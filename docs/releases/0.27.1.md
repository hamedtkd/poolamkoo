# v0.27.1 — Workspace navigation hotfix

این نسخه یک Regression جدی در جابه‌جایی Client-side بین مسیرهای Workspace را اصلاح می‌کند.

## مشکل

در بعضی مرورگرها، جابه‌جایی با Navigation داخلی بین مسیرهایی مثل Reports و Settings می‌توانست Shell را نگه دارد اما محتوای اصلی را خالی کند؛ Refresh کامل صفحه محتوا را دوباره نشان می‌داد.

ریشه مشکل Route-level exit animation بود: کل محتوای Route داخل `AnimatePresence` قرار داشت و هنگام تغییر App Router می‌توانست از DOM/visibility خارج شود. برای صفحات مالی، پایداری Navigation از Fade خروجی مهم‌تر است.

## اصلاح

- Route-level `AnimatePresence` حذف شد.
- Route جدید دیگر هیچ‌وقت با `opacity: 0` شروع یا تمام نمی‌شود.
- Wrapper مسیر حالا یک `div` پایدار و بدون انیمیشن خروج/ورود است؛ Motion فقط در سطح Card/Componentهای غیرحیاتی باقی می‌ماند.
- Motionهای داخل خود Dashboard/Cardها دست‌نخورده‌اند.
- Browser Release Smoke اکنون Reports → Settings → Reports را با کلیک واقعی روی `next/link` و بدون Reload تست می‌کند.
- تست مرورگر با یک marker داخل `window` ثابت می‌کند Navigation واقعاً Client-side مانده و Full document reload رخ نداده است.
- بعد از هر Navigation، وجود و visibility واقعی Route content نیز Assert می‌شود.

## Data safety

- IndexedDB schema همچنان 6 است.
- هیچ migration، تغییر Backup، تغییر Market provider یا ارسال داده جدیدی وجود ندارد.
- Service Worker cache به `poolamkoo-v46` افزایش یافته است.
