# Poolamkoo 0.31.0 — Market transparency & privacy-safe diagnostics

این فاز Health زیرساخت بازار v0.30 را به یک سطح قابل‌فهم و قابل‌استفاده برای کاربر تبدیل می‌کند؛ بدون اضافه‌کردن Provider جدید، Telemetry یا دیتابیس مرکزی.

## تغییرات اصلی

- Settings حالا کارت «وضعیت بازار» دارد و حالت کلی بازار را به‌صورت زنده، محدود، Snapshot محلی، تنظیم‌نشده یا ناموجود نشان می‌دهد.
- وضعیت BrsApi، TSETMC و Tindex جداگانه نمایش داده می‌شود؛ شامل نقش Provider، سلامت، تعداد پاسخ‌های دریافت‌شده/درخواستی و latency تقریبی.
- کاربر می‌تواند همان‌جا refresh بازار را دوباره اجرا کند و نتیجه را بدون رفتن به Dashboard بررسی کند.
- یک Diagnostic متنی قابل‌کپی اضافه شده که فقط metadata عملیاتی را نگه می‌دارد: نسخه برنامه، mode، health code، count، latency و failure category.
- Diagnostic عمداً قیمت، نماد، نام دارایی، market id، مبلغ، متن خطای خام Provider و Secretها را شامل نمی‌شود.
- fallback همچنان فقط از داده واقعی استفاده می‌کند: Provider واقعی → Snapshot واقعی IndexedDB → قیمت دستی کاربر → unavailable.

## چیزهایی که تغییر نکردند

- BrsApi منبع اصلی نرخ‌های پایه است.
- TSETMC منبع اصلی مستقیم بورس تهران است و API Key نمی‌خواهد.
- Tindex فقط legacy/emergency fallback اختیاری باقی مانده است.
- هیچ adapter جدیدی اضافه نشده؛ Provider تازه فقط بعد از تأیید auth/schema/free-tier/deployment behavior وارد محصول می‌شود.
- IndexedDB schema همچنان `6` است و Backup/Restore/Device Transfer migration ندارند.
- Background Push همچنان به‌صورت پیش‌فرض غیرفعال است.
- داده مالی یا Diagnostic به سرور Poolamkoo ارسال نمی‌شود؛ کپی‌کردن Diagnostic فقط با اقدام صریح کاربر انجام می‌شود.
