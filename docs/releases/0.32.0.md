# Poolamkoo 0.32.0 — Market fallback continuity & freshness

این نسخه یک شکاف مهم در fallback بازار را می‌بندد: اگر Refresh فقط بخشی از Quoteها را تازه بگیرد، Quoteهای موفق دیگر به‌خاطر شکست یک Provider از بین نمی‌روند و Quoteهای ناموفقِ مرتبط می‌توانند از آخرین Snapshot واقعی همان نماد روی دستگاه پر شوند.

## چه تغییر کرد؟

- `lib/market/runtime.ts` یک لایه Pure برای merge کردن Quoteهای تازه و Snapshotهای محلی اضافه می‌کند.
- Quote تازه همیشه بر Snapshot قبلی اولویت دارد.
- Snapshot فقط برای نرخ‌های اصلی یا نمادهای بورس/Legacy که واقعاً در همان runtime درخواست شده‌اند وارد نتیجه می‌شود؛ Snapshotهای قدیمی نامرتبط دوباره به UI برنمی‌گردند.
- هویت نماد بورسی Provider-scoped باقی می‌ماند؛ Snapshot یک TSETMC id جای رکورد Legacy Tindex با همان id را نمی‌گیرد.
- `useMarket` در Refresh ناقص، Quoteهای تازه و fallbackهای واقعی را همزمان نگه می‌دارد و فقط Quote تازه Provider را دوباره در IndexedDB ذخیره می‌کند.
- Dashboard، سبد، دیده‌بان و جزئیات بازار کنار Provider صریحاً `Snapshot محلی` را نشان می‌دهند.
- Settings تعداد Quoteهای تازه و Snapshotهای فعال و زمان قدیمی‌ترین Snapshot fallback را نشان می‌دهد. Diagnostic امن نیز فقط همین count/timestamp عملیاتی را اضافه می‌کند و همچنان هیچ قیمت، نماد، نام دارایی، market id، مبلغ یا Secret ندارد.
- هشدار محلی قیمت/تغییر/NAV فقط Quote تازه را ارزیابی می‌کند. Snapshot fallback برای تداوم نمایش/ارزش‌گذاری است و نباید یک Notification جدید یا re-arm مصنوعی ایجاد کند.
- Summary «مثبت امروز» دیده‌بان نیز Quote فقط-Snapshot را به‌عنوان حرکت تازه امروز حساب نمی‌کند.

## قرارداد fallback

ترتیب همچنان تغییر نکرده است:

1. Quote واقعی تازه Provider
2. آخرین Snapshot واقعی مرتبط روی دستگاه
3. قیمت دستی کاربر، اگر برای آن دارایی وجود داشته باشد
4. وضعیت ناموجود / cost-basis fallback در جایی که محصول از قبل صریحاً آن را پشتیبانی می‌کرد

هیچ Quote، History، NAV یا تغییر روزانه مصنوعی ساخته نمی‌شود.

## سازگاری

- IndexedDB schema همچنان `6` است؛ Migration داده لازم نیست.
- Backup، Recovery Snapshot و Device Transfer format تغییر نکرده‌اند.
- BrsApi همچنان منبع اصلی نرخ‌های پایه، TSETMC منبع اصلی نمادهای جدید بورس و Tindex فقط legacy/emergency fallback است.
- Background Push همچنان در Build عادی خاموش است.
- Service Worker cache فقط برای انتشار نسخه جدید bump شده است.

## QA هدفمند

تست‌های جدید merge partial refresh، latest-snapshot selection، جداسازی runtime metadata از ذخیره‌سازی، جلوگیری از alert روی Snapshot، coverage diagnostics و Summary دیده‌بان را پوشش می‌دهند.
