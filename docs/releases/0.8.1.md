# v0.8.1 — Provider fallback و Attribution بازار

## هدف نسخه

بازار نباید با تمام‌شدن سهمیه یا قطع موقت یک Provider از کار بیفتد. BrsApi همچنان منبع اصلی نرخ‌های عمومی است و Tindex فقط وقتی نرخ‌های اصلی ناقص باشند به‌عنوان fallback وارد می‌شود. منبع هر قیمت نیز در UI شفاف نمایش داده می‌شود.

## زنجیره Provider

برای نرخ‌های عمومی فعلی پولم‌کو:

```text
BrsApi → Tindex → آخرین Snapshot واقعی → قیمت دستی دارایی
```

- BrsApi برای دلار، طلای ۱۸ عیار، بیت‌کوین و تتر منبع اصلی باقی می‌ماند.
- اگر BrsApi قطع شود، 429/5xx بدهد یا بعضی Quoteهای اصلی را برنگرداند، پولم‌کو یک درخواست `Tindex /boards` می‌زند.
- همان درخواست Tindex در fallback، دلار، طلای ۱۸ عیار و بیت‌کوین را پوشش می‌دهد.
- برای جلوگیری از مصرف بی‌دلیل سهمیه Tindex، وقتی BrsApi همه Quoteهای اصلی را دارد fallback فراخوانی نمی‌شود.
- تتر در این فاز همچنان از BrsApi و سپس Cache/Manual fallback استفاده می‌کند؛ برای گرفتن Tether-Dollar از Tindex به درخواست جداگانه نیاز است و عمداً به سهمیه رایگان تحمیل نشده است.

## بورس و ETF

سهام و صندوق‌های بورسی متصل‌شده همچنان مستقیماً از Tindex/TSETMC قیمت می‌گیرند. قیمت بورس در API بر حسب ریال است و قبل از ورود به مدل داخلی به تومان تبدیل می‌شود. این تبدیل فقط برای stock endpoints انجام می‌شود؛ indicatorهای عمومی Tindex اکنون مستقیماً تومان هستند.

## اولویت Quote

اگر BrsApi و Tindex هر دو برای یک نماد عمومی قیمت برگردانند، Quote مربوط به BrsApi حفظ می‌شود. Tindex فقط جای خالی Provider اصلی را پر می‌کند و قیمت معتبر BrsApi را override نمی‌کند.

## Attribution

هرجا Quote واقعی Tindex نمایش داده شود، UI لینک `منبع داده: Tindex` به `https://tindex.app` نشان می‌دهد. این Attribution در کارت بازار، Portfolio، قیمت فعلی نمودار و جست‌وجوی نماد بورسی استفاده می‌شود.

## تست

- تبدیل قیمت ریالی بورس Tindex به تومان
- حفظ مستقیم قیمت تومانی indicatorهای عمومی Tindex
- ساخت fallback دلار، طلا و BTC از یک پاسخ Boards
- حفظ اولویت BrsApi هنگام وجود Quote تکراری
- Regression check برای Attribution لینک‌شده Tindex
