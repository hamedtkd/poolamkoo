# v0.29.0 — Privacy-safe report export & mobile UX refinement

این فاز خروجی گزارش را بدون تبدیل پولم‌کو به نرم‌افزار حسابداری اضافه می‌کند و هم‌زمان ناوبری موبایل، Skeletonها و Motion داخل Workspace را یکدست‌تر می‌کند.

## Report export/share

- صفحه Reports یک کنترل صریح «خروجی و اشتراک» دارد.
- متن اشتراک فقط درصدهای تصمیمی را می‌فرستد: اجرای برنامه، پوشش صندوق‌ها، پوشش تخصیص و نسبت‌های زندگی/امنیت/رشد.
- متن اشتراک عمداً **مبلغ‌ها و نام دارایی‌ها** را حذف می‌کند.
- CSV کامل فقط با اقدام مستقیم کاربر روی همان دستگاه ساخته می‌شود و می‌تواند مبلغ‌ها و نام/ارزش دارایی‌ها را داشته باشد.
- CSV شامل تراکنش خام، Backup payload یا داده مخفی دیگری نیست.
- نام‌های کاربرمحور که با `=`, `+`, `-`, `@` شروع شوند قبل از CSV خنثی می‌شوند تا Spreadsheet formula injection ایجاد نشود.
- هیچ لینک Share میزبانی‌شده یا دیتابیس سروری برای گزارش اضافه نشده است.

## Mobile navigation/search

- More sheet دیگر مقصدهای اصلی Bottom Navigation را دوباره تکرار نمی‌کند.
- «پول جدید دارم» یک CTA واضح است و Reports/Settings به‌عنوان کارهای ثانویه باقی مانده‌اند.
- ابزارهای بازار، Privacy، Theme و Tour داخل یک نوار Utility فشرده قرار گرفته‌اند.
- لینک‌های راهنما/حریم خصوصی/درباره سبک‌تر شده‌اند.
- Global Search روی موبایل به Drawer تبدیل شده و قبل از تایپ فقط سه میانبر نشان می‌دهد، نه فهرست بلند همه Routeها.
- Drawer واقعاً با Drag دستگیره به پایین بسته می‌شود؛ Drag با CSS `translate` مستقل از transform animation اجرا می‌شود تا انیمیشن بازشدن با حرکت دست تداخل نداشته باشد.

## Motion and responsive continuity

- Header همچنان از بالا وارد می‌شود، اما KPIها و Cardهای Workspace همگی با یک جهت `fade-up` و stagger کوتاه ظاهر می‌شوند؛ ورود متقارن چپ/راست حذف شد.
- در عرض‌های Desktop فشرده، Sidebar به rail 64px قفل می‌شود تا محتوای گزارش/جدول فضای کافی داشته باشد.
- Mobile safe-bottom بزرگ‌تر شده تا Bottom Navigation روی آخرین Cardها قرار نگیرد.
- Skeletonها با Header/CTA، Decision summary و Sidebar responsive واقعی هماهنگ‌تر شده‌اند و فاصله خالی بالای Route کمتر شده است.

## Release gates

- Pure tests مرز Privacy متن Share، CSV detail و formula neutralization را بررسی می‌کنند.
- Browser release smoke کنترل Export را باز می‌کند و Drag-to-dismiss منوی موبایل را با Pointer input واقعی تست می‌کند.
- IndexedDB schema همچنان `6` است.
- Service Worker cache برابر `poolamkoo-v53` است.
- Background Push همچنان پیش‌فرض خاموش است.
