# v1.1.0 — Searchable settings architecture

`v1.1.0` اولین Feature Release بعد از v1.0.x است و صفحه بلند و متراکم Settings را به یک معماری دسته‌بندی‌شده و قابل جست‌وجو تبدیل می‌کند. این تغییر از الگوی registry + route + deep-link در پروژه Saat-yar الهام گرفته، اما برای جریان‌های مالی Poolamkoo ساده‌تر شده است.

## تغییرات اصلی

- `/settings` حالا یک Overview سبک با کارت‌های دسته‌بندی است و دیگر همه کنترل‌ها را هم‌زمان رندر نمی‌کند.
- تنظیمات در مسیرهای مستقل **عمومی و ظاهر**، **برنامه پول**، **بازار و قیمت‌ها**، **داده و بکاپ**، **انتقال دستگاه**، **حریم خصوصی و نصب** و **راهنما و درباره** پخش شده‌اند.
- یک registry مرکزی عنوان، دسته، کلیدواژه و deep-link هر تنظیم را نگه می‌دارد تا ناوبری و Search از هم جدا نشوند.
- جست‌وجوی خود Settings روی فارسی/عربی نرمال‌شده کار می‌کند و نتیجه را مستقیم به route و anchor مرتبط می‌برد.
- جست‌وجوی سراسری Poolamkoo همان registry را مصرف می‌کند؛ بنابراین عبارت‌هایی مثل «بکاپ»، «قانون پول»، «تم»، «TSETMC» یا «نصب PWA» مستقیماً تنظیم مربوط را باز می‌کنند.
- صفحه بازار ابتدا فقط وضعیت قابل فهم و action اصلی را نشان می‌دهد؛ Providerها، سهمیه و Diagnostic داخل «جزئیات فنی» جمع شده‌اند تا صفحه برای استفاده روزمره شلوغ نباشد.
- Desktop یک ناوبری داخلی sticky برای دسته‌های Settings دارد و Mobile همان دسته‌ها را به شکل نوار افقی اسکرول‌پذیر نشان می‌دهد.
- بخش «عمومی و ظاهر» یک رنگ‌ساز سفارشی دارد: فیلد Saturation/Value، Hue، ورودی Hex، پیش‌نمایش زنده و حداکثر ۸ رنگ ذخیره‌شده. رنگ انتخابی روی `primary`، لوگوی theme-aware، Ring و رنگ‌های نمودار اعمال می‌شود.
- رنگ سفارشی و Swatchهای ذخیره‌شده Local-first هستند؛ داخل همان Settings محلی می‌مانند و همراه Backup تنظیمات منتقل می‌شوند. این قابلیت نیاز به schema bump ندارد.
- Route loading حالا فقط اسکلت محتوای همان صفحه را نشان می‌دهد و App Shell/Sidebar دوم داخل Shell موجود mount نمی‌کند؛ Bootstrap skeleton هم عرض سایدبار collapse‌شده را از همان state واقعی دنبال می‌کند تا فضای خالی و پرش افقی ایجاد نشود.

## مرزهای ثابت

- IndexedDB همچنان **schema 8** است و migration داده نداریم.
- Backup/Recovery/Device Transfer، Local-first ownership و privacy boundary تغییر نکرده‌اند.
- Provider priority، quota hardening نسخه `v1.0.1` و SVG/PWA brand identity نسخه `v1.0.2` حفظ شده‌اند.
- تغییر فقط IA، navigation، search و presentation تنظیمات است؛ رفتار مالی موجود بازنویسی نشده است.

## Gate انتشار

قبل از Tag/Release باید `npm run check:stable` کامل سبز باشد و مرور دستی Settings روی Desktop/Mobile شامل Search، deep-link، Back/Forward و تمام دسته‌ها بدون blocker تأیید شود.
