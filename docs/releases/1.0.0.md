# v1.0.0 — First stable release

`v1.0.0` اولین نسخه Stable پولم‌کو است. این Release یک Feature phase جدید نیست؛ همان Runtime پذیرفته‌شده `v1.0.0-rc.3` را بعد از عبور Gate کامل Production و Manual Acceptance به Stable ارتقا می‌دهد.

## مبنای Stable

- `npm run check:stable` کل `check:release` را اجرا می‌کند و سپس Version/Schema/Docs نهایی را کنترل می‌کند.
- Production Browser Smoke migration واقعی IndexedDB از schema 6 به schema 8، Landing → Workspace، onboarding/bootstrap محلی، راهنمای سریع، Reports، mobile drawer، client-side navigation و مرزهای PWA را پوشش می‌دهد.
- Manual Acceptance روی Desktop/Mobile برای راهنمای سریع، نصب/Update PWA، Offline/Resume، Backup → Restore، old-tab upgrade و Responsive/Theme تأیید شده است.
- blocker راهنمای سریع که در RC1 دیده شد در RC3 با SVG mask cutout، Target دقیق و Browser Smoke قطعی Desktop/Mobile پایدار شد.
- `clean:obsolete` فایل‌های RC-only مثل `tests/v1-rc.test.ts` و `scripts/check-v1-rc.mjs` را اگر از Extract نسخه Stable روی checkout قبلی باقی مانده باشند حذف می‌کند تا Gate Stable با assertionهای منقضی RC اشتباه Fail نشود.

## مرز داده و محصول

- IndexedDB همچنان **schema 8** است؛ Stable هیچ migration جدیدی نسبت به RC3 اضافه نمی‌کند.
- Backup/Recovery/Device Transfer contract تغییر نکرده است.
- Provider جدید، backend مالی، account system، cloud sync یا Feature Family جدیدی در promotion به Stable اضافه نشده است.
- Runtime local-first و privacy boundaries نسخه Candidate پذیرفته‌شده بدون تغییر حفظ شده‌اند.

## تصمیم Release

RC3 از Gate خودکار Production عبور کرد و Manual Acceptance نهایی بدون blocker تأیید شد. بنابراین مسیر صحیح Release، promotion مستقیم به `v1.0.0` stable است؛ نه ساخت RC جدید یا افزودن Feature در لحظه Release.
