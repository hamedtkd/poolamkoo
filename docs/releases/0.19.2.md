# v0.19.2 — Workspace route-group migration

This patch removes the ambiguous `(app)` route-group name and hardens replacement installs against stale Next.js generated route validators.

## Changes

- Renamed the financial route group from `app/(app)` to `app/(workspace)`.
- Kept public URLs unchanged: `/dashboard`, `/income`, `/funds`, `/investments`, `/reports`, and `/settings` still resolve exactly as before because route-group names are not part of the URL.
- Replacement cleanup now removes the entire legacy `app/(app)` tree when the new workspace entry exists.
- `clean:obsolete` also removes `.next/types` and `.next/dev/types` so TypeScript cannot import validators generated for a route that no longer exists.
- Regression checks now enforce the `(workspace)` layout and the stale-validator cleanup contract.
- Service-worker cache version bumped to `poolamco-v35` so clients refresh the hardened shell after deployment.

No financial data migration is required. IndexedDB remains attached to the same origin and is unaffected by the route-group folder rename.
