# Poolamkoo v0.38.0 — Fund movement ledger & correction safety

این نسخه موجودی صندوق‌های هدف را از یک عدد قابل‌ویرایش مستقیم به یک دفتر گردش محلی و قابل‌ممیزی ارتقا می‌دهد.

## چه تغییر کرد؟

- `fundMovements` به‌عنوان تاریخچه مستقل واریز، برداشت و موجودی آغازین اضافه شد؛ `fund.currentToman` برای خواندن سریع باقی می‌ماند اما از روی دفتر گردش sync می‌شود.
- واریز/برداشت دستی حالا تاریخ و یادداشت دارد و ردیف دستی را می‌توان اصلاح یا حذف کرد. هر تغییر با replay زمانی بررسی می‌شود و اگر موجودی در هر روز منفی شود، عملیات رد می‌شود.
- گردش‌های سیستمیِ اجرای برنامه، کنارگذاری مستقیم پول جدید و برگشت حذف ورودی از همان mutation boundary عبور می‌کنند و برای audit read-only هستند.
- ویرایش صندوق دیگر اجازه تغییر مستقیم موجودی را نمی‌دهد؛ موجودی فقط از مسیر واریز/برداشت/اجرای واقعی تغییر می‌کند.
- حذف صندوق با موجودی مثبت یا برنامه انجام‌نشده مسدود می‌شود؛ حذف امن، دفتر گردش همان صندوق را نیز همراه Recovery Snapshot پاک می‌کند.
- Backup/Restore و Device Transfer تعداد گردش‌های صندوق را در Preview نشان می‌دهند. Payload قدیمی بدون جدول جدید همچنان پذیرفته می‌شود و موجودی مثبت قدیمی پیش از persistence به یک opening migration تبدیل می‌شود.

## Migration و سازگاری

- IndexedDB از schema 7 به **schema 8** می‌رود؛ نام دیتابیس `poolyar-local` و primary keyهای قبلی تغییر نمی‌کنند.
- در migration، برای هر صندوق قدیمی با موجودی مثبت یک ردیف `type: opening` و `source: migration` ساخته می‌شود. صندوق با موجودی صفر ردیف مصنوعی نمی‌گیرد.
- اگر Backup/Recovery/Transfer جدید خودش `fundMovements` داشته باشد، orphan row، نوع/منبع نامعتبر، مبلغ غیرمثبت، تاریخچه منفی یا اختلاف موجودی نهایی با `fund.currentToman` پیش از destructive replacement رد می‌شود.
- Browser Release Gate حالا Fixture واقعی schema 6 را تا native version 80/schema 8 ارتقا می‌دهد؛ هم migration هویت بازار schema 7 و هم opening fund ledger schema 8 را قبل از Smoke معمول بررسی می‌کند.

## مرزهای نسخه

- Providerهای بازار، ترتیب BrsApi/TSETMC/Tindex، Snapshot safety و Background Push تغییر نکرده‌اند.
- Backup envelope v1/v2 و پروتکل Direct Transfer تغییر نکرده‌اند.
- Service Worker cache این نسخه `poolamkoo-v62` است.
