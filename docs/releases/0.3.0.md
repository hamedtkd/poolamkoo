# v0.3.0 — گزارش شفاف‌تر و Privacy Mode

## هدف
این فاز ابهام بین «تغییر روزانه بازار» و «سود/زیان شخصی کاربر» را حذف می‌کند و گزارش‌ها را برای استفاده روزمره خواناتر می‌سازد.

## تغییرات
- `بازده از خرید` بر اساس Cost Basis واقعی کاربر محاسبه و در UI صریحاً توضیح داده می‌شود.
- `فاصله از هدف` جایگزین اصطلاح مبهم `انحراف` شد.
- Tooltip برای شاخص‌های گزارش اضافه شد.
- Privacy Mode با آیکون چشم به Sidebar و Mobile Header اضافه شد و اعداد مالی را محو می‌کند.
- Monthly chart برای نبود داده واقعی Empty State دارد.
- Sidebar و Mobile Header از متن‌های توضیحی غیرضروری پاک شدند.
- Market cards تغییر قیمت روزانه Provider را جدا از بازده شخصی نشان می‌دهند.

## تعریف اعداد
- **تغییر روزانه بازار:** `MarketQuote.changeValueToman` و `changePercent` از Provider.
- **سود/زیان باز شما:** `currentValue - cost` برای موجودی واقعی کاربر.
- **بازده از خرید:** `unrealized / cost * 100`.
- **فاصله از هدف:** `actualPortfolioPct - targetPct`.

## تست
تست `portfolio-position.test.ts` اثبات می‌کند مثال خرید ۳,۰۰۰,۰۰۰ تومان دلار با افت قیمت از ۱۰۰,۰۰۰ به ۹۹,۷۰۰ تومان، دقیقاً ۹,۰۰۰ تومان زیان باز شخصی و ۰.۳٪- بازده ایجاد می‌کند؛ این عدد تغییر روزانه بازار نیست.
