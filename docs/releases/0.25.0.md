# v0.25.0 — Reports decision insights and landing product media

این نسخه دو کار محصولی را با هم کامل می‌کند: گزارش‌ها از نمایش صرف عددها به یک مرور تصمیمی قابل‌فهم تبدیل می‌شوند و Landing بالاخره تصویر واقعی/مفهومی هماهنگ با تم روشن و تاریک دارد.

## گزارش‌ها و بینش‌های تصمیمی

- کارت جدید «جمع‌بندی تصمیمی این بازه» وضعیت اجرای برنامه، تعادل قانون پول و پوشش فعلی صندوق‌ها را کنار هم نشان می‌دهد.
- مقایسه زندگی / امنیت / رشد فقط از Allocationهای واقعی همان بازه ساخته می‌شود؛ وقتی داده‌ای وجود ندارد، درصدهای قانون به‌عنوان داده واقعی جعل نمی‌شوند.
- اگر همه پول‌های ورودی بازه هنوز تخصیص نشده باشند، گزارش صریحاً «تخصیص ناقص» نشان می‌دهد و راهنمای مقایسه با قانون را معتبر فرض نمی‌کند.
- فاصله از قانون پول با تحمل یک واحد درصد و به‌صورت deterministic محاسبه می‌شود.
- «برای مرور بعدی» فقط پیگیری‌های مبتنی بر داده ثبت‌شده را مطرح می‌کند؛ این بخش نه حسابداری هزینه روزمره است، نه پیش‌بینی بازار و نه توصیه خرید/فروش.
- Donut تقسیم پول در حالت بدون داده دیگر ۱۰۰٪ مصنوعی نمایش نمی‌دهد و Empty State واقعی دارد.

## Landing و رسانه محصول

- Hero لندینگ از دو تصویر تأییدشده Light/Dark استفاده می‌کند و با Theme فعال سوییچ می‌شود.
- تصاویر با WebP بهینه شده‌اند و داخل Repository قرار دارند؛ Landing برای نمایش آن‌ها به سرویس تصویری خارجی وابسته نیست.
- متن کنار تصویر روشن می‌کند که عددهای داخل تصویر داده نمایشی هستند، نه داده کاربر یا قیمت زنده بازار.
- تصویر مفهومی جریان واقعی محصول را نشان می‌دهد: پول ورودی، تقسیم پول، صندوق هدف، ترکیب سبد و هدف مالی؛ «خرج‌های روزانه / تراکنش خرید فروشگاهی» به محصول نسبت داده نمی‌شود.

## Product media capture

- `media:capture:built` دیگر برای بالا آوردن Production Server روی Windows به `npm.cmd` child process وابسته نیست؛ Next.js با Node runtime و bin نصب‌شده خودش اجرا می‌شود تا خطای `spawn EINVAL` حذف شود.
- Capture حالا Landing را هم در Light و هم Dark ثبت می‌کند.
- Browser Profile موقت، Fixture نمایشی و Block شدن Market/Push/Analytics همان مرز Privacy-safe نسخه قبل را حفظ می‌کنند.

## Data safety / architecture

- IndexedDB schema همچنان **6** است.
- Backup/Restore و Device Transfer format تغییری نکرده‌اند.
- هیچ داده مالی جدیدی به Server یا Analytics ارسال نمی‌شود.
- هیچ Market provider یا fetch frequency جدیدی اضافه نشده است.
- Background Push همچنان خاموش و در Backlog است.
- Service Worker cache به `poolamkoo-v42` ارتقا یافته است.

## Release verification

```bash
npm install
npm run check
npm run build
npm run media:capture:built
```

Capture رسانه یک QA تکمیلی است؛ `npm run check` همچنان TypeScript، ESLint، تست‌ها، UI/performance/regression gates و icon import validation را اجرا می‌کند.
