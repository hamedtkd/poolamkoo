# v0.27.0 — Public landing experience and theme continuity

این نسخه سطح عمومی Poolamkoo را بازطراحی می‌کند تا Hero واقعاً در اولین رندر دیده شود و Light/Dark روی خود Landing قابل کنترل باشد.

## تغییرات

- Hero لندینگ با سلسله‌مراتب کوتاه‌تر، CTA واضح‌تر و تصویر محصول بزرگ‌تر بازطراحی شد.
- تصاویر تأییدشده `poolamkoo-finance-light.webp` و `poolamkoo-finance-dark.webp` همان دارایی‌های محلی قبلی هستند و بر اساس تم نمایش داده می‌شوند.
- محتوای حیاتی Hero از `MotionReveal` خارج شد تا در صورت تأخیر یا شکست Hydration با opacity صفر پنهان نماند.
- انیمیشن‌های ورود، glow و float با CSS پیاده شده‌اند و در `prefers-reduced-motion` کاملاً غیرفعال می‌شوند.
- هدر عمومی یک Theme Toggle مستقل دارد؛ این کنترل فقط از `next-themes` استفاده می‌کند و برای تغییر تم به IndexedDB مالی دست نمی‌زند.
- Transition تغییر تم در مرورگرهای دارای View Transition API نرم است و fallback بدون انیمیشن دارد.
- Browser Release Smoke اکنون لود واقعی تصویر Hero و تغییر تم عمومی را قبل از ورود به Workspace بررسی می‌کند.
- Service Worker cache به `poolamkoo-v45` ارتقا یافت.

## Data / privacy

- IndexedDB schema همچنان 6 است.
- Backup/Restore و Device Transfer تغییری نکرده‌اند.
- Landing همچنان Service Worker را initialize نمی‌کند و PWA Manifest فقط متعلق به Workspace است.
- هیچ داده مالی جدیدی به Analytics یا Server ارسال نمی‌شود.
