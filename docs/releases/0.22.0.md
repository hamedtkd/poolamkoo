# v0.22.0 — Mobile navigation and accessibility hardening

This release improves the everyday mobile path and keyboard/screen-reader semantics without changing the local financial data model.

## Mobile daily flow

- The fixed mobile navigation now keeps Home, Incoming Money, Investments, and Funds one tap away.
- Reports, Settings, public help/trust links, market refresh, privacy, theme, and product help remain available from the More sheet.
- The bottom navigation and app content now account for `safe-area-inset-bottom`, reducing overlap with device gesture/home-indicator areas.
- Touch targets in the mobile header and bottom navigation are at least 44px-class targets.

## Keyboard and screen-reader accessibility

- Active desktop/mobile routes expose `aria-current="page"`.
- The More controls expose expanded/dialog state and connect to the mobile sheet.
- Global Search now uses combobox/listbox semantics, supports Arrow Up/Down plus Home/End, keeps a visible active result, and announces result counts through a polite live region.
- Dialog close controls and Drawer descriptions have explicit accessible names/descriptions.
- Sortable data-table headers expose `aria-sort`; pagination is a labelled navigation landmark.
- Previously icon-only edit/delete/refresh/archive/alert controls in key financial surfaces now have explicit accessible labels.

## Compatibility and privacy

- IndexedDB schema remains version 6; no migration is required.
- No account, backend financial database, new third-party analytics event, or server cost is introduced.
- Background Push remains disabled by default and in backlog.
- Service Worker cache advances to `poolamco-v38` so shell changes activate as one release after user-approved update.

## QA focus

Release verification should include 360/390/430px mobile widths, Android/iOS-style bottom safe areas, keyboard-only desktop navigation, screen-reader naming for icon buttons, global-search arrow navigation, and the normal `npm run check` / `npm run build` gates.
