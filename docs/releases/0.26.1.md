# v0.26.1 — PWA boundary replacement-install hotfix

این Patch یک Regression واقعی را که Browser Release Smoke در v0.26 پیدا کرد رفع می‌کند.

## مشکل

در نسخه‌های قبل، Manifest نصب PWA یک Next.js special route در `app/manifest.ts` بود. از v0.24 Manifest جدید به `public/app.webmanifest` منتقل شد و فقط Workspace آن را advertise می‌کند. اما روش توسعه Poolamkoo بر پایه جایگزینی سورس کامل است و Extract/Copy فایل‌های جدید، فایل‌هایی را که دیگر در ZIP وجود ندارند حذف نمی‌کند.

در نتیجه یک checkout قدیمی می‌توانست `app/manifest.ts` را نگه دارد. Next.js آن فایل باقی‌مانده را دوباره به `/manifest.webmanifest` تبدیل می‌کرد و Landing عمومی ناخواسته `rel=manifest` دریافت می‌کرد. Browser Smoke v0.26 دقیقاً همین حالت را روی Build واقعی پیدا کرد.

## اصلاح

- `clean:obsolete` اکنون `app/manifest.ts` و variantهای legacy آن را هنگام وجود Workspace جدید حذف می‌کند.
- `public/app.webmanifest` دست‌نخورده می‌ماند و Manifest رسمی نصب همچنان `id/start_url=/dashboard` دارد.
- تست integration جدید سناریوی «جایگزینی سورس روی checkout قدیمی» را در یک پوشه موقت بازسازی می‌کند و حذف Manifest قدیمی را اثبات می‌کند.
- PWA regression gate نیز حضور cleanup مخصوص Manifest قدیمی را الزام می‌کند.
- Service Worker cache به `poolamkoo-v44` ارتقا یافت.

## Data safety

- IndexedDB schema همچنان 6 است.
- هیچ Migration، Reset، تغییر Backup یا تغییر داده مالی انجام نشده است.
- پاک‌سازی فقط entrypoint قدیمی کد/Route را حذف می‌کند و به IndexedDB، Local Storage مالی یا Backupها دست نمی‌زند.

## Release verification

```bash
npm install
npm run check
npm run build
npm run test:browser:release:built
```

در اولین `npm run check` بعد از جایگزینی سورس روی checkout قدیمی باید در صورت وجود این پیام دیده شود:

```text
Removed obsolete route: app/manifest.ts
```

پس از Build، Landing عادی نباید Manifest نصب advertise کند و Browser Smoke باید کامل سبز شود.
