# v0.15.1 — Device transfer typecheck fix

این Patch هیچ رفتار محصولی جدیدی اضافه نمی‌کند و فقط خطای TypeScript گزارش‌شده در کارت انتقال بین دستگاه‌ها را رفع می‌کند.

## Fix

- `Badge` داخلی پولم‌کو propای با نام `variant` ندارد و ظاهر ثانویه در همین کامپوننت، ظاهر پیش‌فرض Badge است.
- سه `variant="secondary"` اشتباه از `DeviceTransferCard` حذف شدند.
- هیچ API یا قرارداد عمومی Badge تغییر نکرد تا سطح تغییر حداقلی بماند.
- Service Worker cache به `poolamco-v29` bump شد تا Patch جدید در PWA به‌صورت قابل اتکا دریافت شود.

## Verification

این Patch دقیقاً خطای `TS2322` گزارش‌شده برای `components/settings/device-transfer-card.tsx` را هدف می‌گیرد. Quality gate کامل باید روی محیط دارای dependency با `npm run check` و سپس `npm run build` اجرا شود.
