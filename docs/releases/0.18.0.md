# v0.18.0 — Privacy-first usage analytics

این نسخه یک مسیر رایگان و اختیاری برای فهمیدن میزان استفاده واقعی از پولم‌کو اضافه می‌کند، بدون ساختن event tracking برای رفتارهای مالی کاربران.

## تغییرات

- اتصال اختیاری Cloudflare Web Analytics با Beacon رسمی و بدون dependency تحلیلی npm.
- اجرای Analytics فقط در Production و فقط وقتی `NEXT_PUBLIC_CLOUDFLARE_WEB_ANALYTICS_TOKEN` معتبر تنظیم شده باشد.
- Self-host بدون توکن هیچ Script تحلیلی خارجی Render نمی‌کند.
- استفاده از SPA measurement خود Cloudflare برای Page View و route changeها.
- عدم تعریف Custom Event برای مبلغ، تراکنش، دارایی، جست‌وجو، فرم، Backup یا انتقال دستگاه.
- صفحه عمومی `/analytics` برای توضیح دقیق داده‌های اندازه‌گیری‌شده و مرزهای حریم خصوصی.
- کارت وضعیت Analytics در Settings بدون نمایش توکن.
- به‌روزرسانی Privacy، Security، README، Roadmap و Release QA.
- اضافه‌شدن تست مستقل برای Feature Gate و validation توکن Cloudflare.
- Service Worker cache version به `poolamkoo-v32` ارتقا یافت.

## هدف محصول

برای نسخه عمومی فقط لازم است بدانیم اپ واقعاً استفاده می‌شود، چه صفحه‌هایی بازدید می‌شوند و Core Web Vitals چه وضعی دارند. داده مالی کاربر نباید تبدیل به telemetry شود.
