# v0.3.1

Maintenance and release-readiness work focused on navigation, search, PWA identity, table semantics, and production type safety.

## Navigation and discovery

- Reworked the collapsed desktop sidebar so the brand mark and expand control never overlap.
- Added tooltip-backed icon navigation in collapsed mode.
- Added global search for routes, incoming-money records, funds, and assets.
- Added `Ctrl/Cmd + K` and `/` shortcuts for opening search outside text inputs.
- Added a mobile search entry point.

## Data table and hydration safety

- Updated the shared DataTable generic to satisfy TanStack Table v9 `RowData` constraints.
- Removed sortable-header button nesting. Sorting now uses a dedicated sibling control so help tooltips can remain interactive without producing invalid `<button>` descendants.

## Build hardening

- Hardened new-money allocation persistence around numeric values before writing to IndexedDB.
- Kept the App Router route-group architecture as the single application shell; no legacy `app/page.tsx`/`AppSection` flow is included.

## PWA identity

- Added a theme-aware SVG favicon based on the official Poolamkoo logo.
- Regenerated install icons from the official logo.
- Added the favicon to metadata and Service Worker precache.
- Bumped the Service Worker cache namespace.

## Documentation

- README files are stable product documentation only.
- Release-specific changes stay under `docs/releases/`.
