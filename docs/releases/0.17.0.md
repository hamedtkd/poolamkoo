# v0.17.0 — Motion and dashboard polish

این نسخه روی حس استفاده و خوانایی داشبورد تمرکز دارد، بدون اینکه انیمیشن به مانع کار مالی تبدیل شود.

## تغییرات

- افزودن پکیج مدرن `motion` و `MotionConfig` سراسری با `reducedMotion="user"`.
- transition کوتاه و هم‌زمان بین routeهای داخل اپ؛ بدون نگه‌داشتن کاربر پشت animation.
- حرکت محدود و stagger ملایم KPIهای داشبورد و برجسته‌کردن «سرمایه فعلی» به‌عنوان KPI اصلی.
- active indicator نرم در navigation دسکتاپ و موبایل با `layoutId`.
- ورود/خروج نرم Toastها با `AnimatePresence`.
- Skeleton shimmer آرام با fallback کامل برای `prefers-reduced-motion`.
- خاموش‌شدن animationهای Recharts در Sparkline، Portfolio Area و Monthly Bars وقتی Reduce Motion فعال است.
- Empty stateهای واقعی‌تر برای بازار، نمودار سرمایه و صندوق‌های هدف؛ دیگر فضای خالی یا متن «در حال دریافت» اشتباه نمایش داده نمی‌شود.
- micro-interaction محدود برای Button، Market card و Fund card بدون جابه‌جایی در Reduce Motion.
- افزودن `.gitattributes` برای نگه‌داشتن LF در repository و کاهش نویز CRLF روی Windows.

## اصل UX

Motion در پولم‌کو برای نشان‌دادن تغییر state و حفظ continuity است؛ نه برای تزئین. هیچ animation نباید ورود داده، بازشدن فرم یا خواندن عدد مالی را به تأخیر بیندازد.
