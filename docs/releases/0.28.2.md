# v0.28.2 — Turbopack animation resolver & modal safety

این نسخه یک Hotfix انتشار برای مشکلات واقعی v0.28.1 روی Windows/Next.js Turbopack است.

## اصلاح‌ها

- `tailwindcss-animated@2.1.0` همچنان dependency رسمی انیمیشن‌های CSS Workspace است، اما Tailwind v4 آن را از مسیر صریح `tailwindcss-animated/src/index.css` وارد می‌کند. خود پکیج در `package.json` فیلد `style: src/index.css` دارد، اما Resolve کردن bare CSS import در Turbopack Dev روی Windows قابل اتکا نبود.
- `npm run check:animations` اضافه شد و قبل از TypeScript بررسی می‌کند که هم CSS entry پکیج و هم `motion/react` واقعاً از `node_modules` قابل resolve باشند.
- بدنه `Dialog` و `AlertDialog` دیگر از `animate-fade-up` استفاده نمی‌کند، چون keyframe رسمی آن در 0% `opacity: 0` دارد و می‌تواند Browser Smoke یا UI واقعی را برای یک فریم خالی کند. بدنه Modalها اکنون transform-only است و همیشه opacity خوانا دارد.
- Drawer هم entrance transform-only دارد؛ Overlay و Toast همچنان از utilityهای `tailwindcss-animated` استفاده می‌کنند.
- خطای ESLint `prefer-const` در مسیر `/api/market` اصلاح شد.
- `motion` همچنان برای revealهای viewport/scroll لندینگ باقی می‌ماند و Workspace route-level animation ندارد.
- نسخه برنامه `0.28.2` و Service Worker cache برابر `poolamkoo-v52` است.

## بدون تغییر

- IndexedDB schema همچنان 6 است.
- معماری TSETMC / BrsApi / Tindex نسخه 0.28 تغییر نکرده است.
- Backup/restore/device transfer تغییری ندارند.
- Background Push همچنان به‌صورت پیش‌فرض خاموش است.
