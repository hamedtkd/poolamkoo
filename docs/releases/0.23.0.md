# v0.23.0 — Performance and Core Web Vitals

این نسخه بار JavaScript اولیه مسیرهای مالی را بدون تغییر مدل داده یا رفتار Offline کم می‌کند.

## تغییرات

- Sparklineهای Dashboard دیگر برای چهار نمودار کوچک، Recharts را وارد مسیر اولیه نمی‌کنند و با SVG سبک از داده واقعی Snapshotها رسم می‌شوند.
- نمودار روند سبد Dashboard پشت Dynamic Import مستقل قرار گرفت.
- نمودار ماهانه Reports پشت Dynamic Import مستقل قرار گرفت.
- نمودارهای بازار مبتنی بر `lightweight-charts` در صفحه سرمایه‌گذاری و Dialog جزئیات فقط از مسیر Lazy Chart بار می‌شوند.
- برای مرزهای Lazy، Loading Placeholder با Reduced Motion-safe behavior اضافه شد.
- `check:performance` به Release gate اضافه شد تا واردشدن دوباره مستقیم Chart libraryهای سنگین به مسیرهای اصلی Regression محسوب شود.
- تست هندسه Sparkline اضافه شد تا SVG سبک در داده خالی، تخت و متغیر رفتار پایدار داشته باشد.
- Service Worker cache به `poolamco-v39` ارتقا یافت؛ Offline behavior و Update UX نسخه‌های قبل دست‌نخورده مانده است.

## Data safety / privacy

- IndexedDB schema تغییر نکرده است.
- هیچ داده مالی جدیدی به Server یا Analytics ارسال نمی‌شود.
- هیچ داده مصنوعی برای نمودار ساخته نمی‌شود.
- Background Push همچنان آزمایشی و خاموش است.

## Release verification

```bash
npm install
npm run check
npm run build
```

`npm run check` اکنون `check:performance` را نیز اجرا می‌کند.
