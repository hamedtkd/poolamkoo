# v0.26.0 — E2E release smoke tests

این نسخه یک Browser Release Gate کوچک و واقعی برای مهم‌ترین مرزهای انتشار Poolamkoo اضافه می‌کند؛ بدون Playwright/Cypress و بدون وابستگی جدید.

## تغییرات

- دستور `npm run test:browser:release` ابتدا Production Build را می‌سازد و سپس Smoke Test واقعی را در Chrome/Edge/Chromium اجرا می‌کند.
- دستور `npm run test:browser:release:built` همان Smoke را روی Build موجود اجرا می‌کند.
- دستور `npm run check:release` حالا Quality Gate معمول، Production Build و Browser Smoke را در یک مسیر Release واحد اجرا می‌کند.
- Browser Smoke از یک Profile موقت و خالی استفاده می‌کند و به Profile عادی مرورگر کاربر دسترسی ندارد.
- endpointهای Market و Push و Cloudflare Analytics هنگام Smoke در مرورگر Block می‌شوند تا تست Release سهمیه بازار یا سرویس بیرونی مصرف نکند.
- مسیر عمومی `/` بررسی می‌شود تا Landing باقی بماند، Manifest نصب را منتشر نکند و در Profile تازه Service Worker را راه‌اندازی نکند.
- CTA واقعی Landing به `/dashboard` کلیک می‌شود و Fresh Onboarding از Production Build تأیید می‌شود.
- ایجاد IndexedDB محلی، وضعیت اولیه `onboardingComplete: false` و Persist شدن Skip Onboarding بررسی می‌شوند.
- سپس Fixture مالی کاملاً نمایشی و deterministic در همان Profile موقت Seed می‌شود و Dashboard و Reports واقعی رندر می‌شوند.
- Reports باید `جمع‌بندی تصمیمی این بازه` و مقایسه قانون پول با تخصیص ثبت‌شده را نمایش دهد.
- Workspace باید `/app.webmanifest` را منتشر کند، Manifest با `id/start_url=/dashboard`, `scope=/`, `display=standalone` معتبر باشد و Service Worker در Workspace ثبت شود.
- بعد از ثبت PWA، بازگشت عادی مرورگر به `/` دوباره Landing را نشان می‌دهد و Manifest Workspace از صفحه عمومی حذف می‌شود.
- Workflow دستی GitHub Actions با نام **Release smoke** همان `npm run check:release` را اجرا می‌کند.
- Service Worker cache به `poolamkoo-v43` ارتقا یافته است.

## مرزهای داده و حریم خصوصی

- IndexedDB schema همچنان **6** است و Migration جدیدی وجود ندارد.
- Backup/Restore و Device Transfer format تغییر نکرده‌اند.
- Smoke Test هیچ داده واقعی کاربر را نمی‌خواند و Browser Profile موقت را پس از پایان حذف می‌کند.
- Fixture تست فقط داده ساختگی محلی است و به API خارجی ارسال نمی‌شود.
- Background Push همچنان آزمایشی و غیرفعال باقی مانده است.

## Release verification

برای Release کامل:

```bash
npm install
npm run check:release
```

یا برای عیب‌یابی مرحله‌ای:

```bash
npm run check
npm run build
npm run test:browser:release:built
```

در صورت پیدا نشدن مرورگر، مسیر Chrome/Edge/Chromium را با `POOLAMKOO_BROWSER_PATH` مشخص کن.
