# v1.0.2 — Brand mark & PWA identity refresh

`v1.0.2` یک Patch ظاهری برای یکپارچه کردن هویت Poolamkoo است. لوگوی جدید از فایل SVG نهایی ارائه شده برای نشان P/کیف پول استفاده میکند. هندسه فایل اصلی بدون بازطراحی وارد محصول شده و در UI با CSS mask رنگ تم را میگیرد.

- PWA/Favicon/App icon فقط از **نشان بدون تایپوگرافی** استفاده می‌کنند تا در اندازه کوچک و maskable icon خوانا بمانند.
- در هدرهای باز و نقاطی که نام لازم است، نشان کنار نام فارسی **پولم کو** نمایش داده می‌شود.
- نام انگلیسی `Poolamkoo` برای GitHub، metadata و هویت لاتین پروژه باقی می‌ماند؛ داخل آیکن PWA قرار نمی‌گیرد.
- `icon-192.png`، `icon-512.png` و `maskable-512.png` مستقیما از همان SVG نشان بدون تایپوگرافی تولید میشوند. نسخه های فارسی و انگلیسی SVG نیز به عنوان asset رسمی static/marketing داخل سورس نگه داشته میشوند.
- Service Worker cache به `poolamkoo-v69` bump شده تا نصب‌های موجود assetهای برند جدید را دریافت کنند.
- IndexedDB همچنان schema 8 است و هیچ قرارداد مالی/Backup/Provider تغییر نکرده است.
