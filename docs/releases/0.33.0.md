# Poolamkoo 0.33.0 — Portfolio quote identity & decision safety

این نسخه مرز بین «تداوم نمایش قیمت» و «داده مناسب برای تصمیم خودکار» را صریح می‌کند.

## چه تغییر کرد؟

- Quote دارایی متصل دیگر فقط با `symbol` پیدا نمی‌شود. برای TSETMC/Tindex تطبیق اصلی با `source + marketId` انجام می‌شود و همان قرارداد در Portfolio، Watchlist، Alert، Planning و Reports استفاده می‌شود.
- `Snapshot محلی` همچنان برای نمایش ارزش و حفظ continuity قابل استفاده است، اما `decision-ready` نیست.
- قیمت تازه Provider و قیمت دستی صریح کاربر منابع decision-ready هستند؛ بهای خرید فقط fallback نمایشی است.
- اگر حداقل یک داراییِ موجود قیمت decision-ready نداشته باشد، اولویت خودکار «پول جدید» و تقسیم خودکار بخش رشد تا برگشت قیمت تازه/دستی متوقف می‌شود.
- Reports در همین وضعیت رتبه‌بندی بهترین/بدترین بازده را متوقف می‌کند؛ جدول ارزش فعلی را با منبع قیمت نشان می‌دهد.
- CSV جزئی گزارش یک ستون «منبع ارزش‌گذاری» دارد. خلاصه مناسب اشتراک همچنان مبلغ و نام دارایی را حذف می‌کند.
- هشدارهای محلی فقط Quote تازه و provider-scoped را بررسی می‌کنند. Snapshot نه trigger می‌کند، نه re-arm و نه مقدار پیشنهادی stale برای ساخت هشدار می‌دهد.
- Watchlist، Dashboard و جزئیات بازار تغییر روز Snapshot را به‌عنوان «امروز» نمایش نمی‌دهند و فیلتر/مرتب‌سازی NAV یا mover از Snapshot stale تصمیم نمی‌سازد.
- قیمت Snapshot برای پرکردن خودکار Transaction یا manual fallback دارایی جدید استفاده نمی‌شود.

## Release hygiene

- سه warning باقی‌مانده v0.32 در `lib/market/runtime.ts` حذف شد.
- `npm run lint` حالا با `--max-warnings=0` اجرا می‌شود تا Release Gate روی warning جدید هم متوقف شود.
- dependency جدیدی اضافه نشده است.

## مرزهای ثابت

- BrsApi همچنان Provider اصلی نرخ‌های core است.
- TSETMC همچنان Provider اصلی لینک‌های جدید بورس است.
- Tindex همچنان فقط legacy/emergency fallback است.
- هیچ قیمت، تاریخچه، NAV یا پیش‌بینی ساختگی ایجاد نمی‌شود.
- ترتیب continuity نمایش همچنان Provider واقعی → Snapshot واقعی → قیمت دستی → unavailable است؛ فقط قابلیت‌های تصمیم خودکار سخت‌گیرانه‌تر شده‌اند.
- IndexedDB روی schema 6 می‌ماند و backup/restore/device-transfer migration ندارد.
- Background Push همچنان backlog/experimental و خاموش به‌صورت پیش‌فرض است.
