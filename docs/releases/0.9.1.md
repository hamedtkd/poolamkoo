# v0.9.1 — حفظ انتخاب بازه در حالت بدون داده

در نمودار بازار، انتخاب‌گر «۱ ماه / ۳ ماه» دیگر فقط زمانی که نمودار داده دارد نمایش داده نمی‌شود.

اگر یک بازه داده کافی نداشته باشد یا تاریخچه هنوز در حال دریافت باشد، کنترل بازه همچنان بالای کارت باقی می‌ماند. بنابراین کاربر می‌تواند فوراً به بازه دیگر برگردد؛ مثلاً اگر «۱ ماه» خالی بود دوباره «۳ ماه» را انتخاب کند.

## UX

- Range Picker در حالت داده‌دار، Loading و Empty همیشه قابل دسترس است.
- بازه انتخاب‌شده با `aria-pressed` مشخص می‌شود.
- Empty State نام بازه فعلی را می‌گوید و کاربر را به امتحان بازه دیگر راهنمایی می‌کند.
- تغییر بازه، state انتخاب‌شده را حفظ می‌کند و cache موجود تاریخچه همچنان استفاده می‌شود.

## Regression

Quality gate بررسی می‌کند که Range Picker بیرون از شرط وجود داده رندر شود تا این باگ دوباره برنگردد.
