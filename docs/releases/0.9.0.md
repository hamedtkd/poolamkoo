# v0.9.0 — تاریخچه واقعی بازار و نمودارهای بورس

## هدف نسخه

نمودار سرمایه‌گذاری دیگر برای دلار، طلا و نمادهای بورسی لازم نیست چند روز منتظر Snapshotهای محلی بماند. وقتی Tindex فعال باشد، پولم‌کو تاریخچه واقعی ۱ و ۳ ماهه را از API می‌گیرد و فقط در قطعی یا نبود پشتیبانی به Snapshotهای واقعی همان دستگاه برمی‌گردد.

## History API

Route جدید `GET /api/market/history` اضافه شد:

- `USD` → `USD-EXCHANGE-RATE` در Tindex
- `IR_GOLD_18K` → `GOLD-18K` در Tindex
- دارایی‌های stock/fund متصل → endpoint کندل همان `marketId`
- بازه‌ها: `1m` و `3m`
- interval: روزانه

پاسخ تاریخچه عمومی است و با `s-maxage=3600` و `stale-while-revalidate=86400` cache می‌شود تا تغییر تب، رفرش صفحه و کاربران مختلف بی‌دلیل سهمیه Tindex را مصرف نکنند.

## واحد قیمت

- Indicatorهای دلار و طلای Tindex مستقیماً تومان هستند و بدون تقسیم استفاده می‌شوند.
- کندل‌های بورس/TSETMC ریال هستند و قبل از ورود به مدل داخلی در ۱۰ تقسیم می‌شوند.
- timestamp فشرده و delta-encoded Tindex به تاریخ ISO روزانه تبدیل می‌شود.

## UX نمودار

- دلار و طلای ۱۸ عیار با نمودار خطی نمایش داده می‌شوند؛ چون داده روزانه indicatorها اغلب OHLC یکسان دارد و کندل برای آن‌ها ارزش بصری کمی دارد.
- سهام و ETFهای متصل، کندل OHLC واقعی TSETMC را نمایش می‌دهند.
- انتخاب بازه ۱ ماه / ۳ ماه داخل خود کارت نمودار قرار دارد.
- منبع داده کنار نمودار شفاف نمایش داده می‌شود.
- اگر History آنلاین در دسترس نباشد، Snapshotهای واقعی IndexedDB fallback می‌شوند.
- برای BTC و USDT فعلاً History آنلاین تومانی فعال نشده؛ چون Tindex آن‌ها را با واحد دلار برمی‌گرداند و تبدیل تاریخی معتبر به تومان به سری هم‌زمان USD نیاز دارد. تا آن فاز فقط Snapshot واقعی محلی نمایش داده می‌شود.

## سهمیه API

History فقط برای نماد انتخاب‌شده دریافت می‌شود، requestهای هم‌زمان یکسان در کلاینت dedupe می‌شوند و نتیجه همان نشست در حافظه cache می‌شود. Cache یک‌ساعته سرور نیز مصرف quota را بیشتر کاهش می‌دهد.

## تست‌ها

- decode زمان‌های delta-encoded کندل Tindex
- حفظ قیمت تومانی indicatorها
- تبدیل کندل ریالی بورس به تومان
- حذف ردیف‌های ناقص یا نامعتبر
- Regression برای History route، fallback محلی، attribution و line/candlestick mode

## فاز بعدی پیشنهادی

1. Watchlist بازار جدا از سبد کاربر، با تعداد محدود نماد مورد علاقه.
2. نمایش NAV و حباب قیمت ETFهای طلا/نقره، فقط اگر منبع معتبر API آن را ارائه کند.
3. اتصال یک‌کلیکی دارایی‌های دستی قدیمی مثل «عیار» و «سیمین» به نماد واقعی بورس.
4. History تومانی BTC/USDT با هم‌ترازسازی سری تاریخی دلار، در صورتی که سهمیه API اجازه دهد.
