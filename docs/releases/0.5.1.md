# v0.5.1 — Quality gate و اصلاح معنی نمودار قانون پول

این نسخه یک فاز تثبیت قبل از ادامه قابلیت‌های Import است.

## اصلاح نمودار قانون پول

- عدد داخل حلقه دیگر امتیاز نرمال‌شده و مبهم نیست.
- مقدار حلقه دقیقاً برابر `امنیت + رشد` است؛ برای قانون ۳۰/۲۰/۵۰، مقدار درست **۷۰٪** نمایش داده می‌شود.
- همان منطق در آنبوردینگ و داشبورد استفاده می‌شود تا دو نمایش از یک قانون معنی متفاوت نداشته باشند.
- `ArcGauge` عنوان و `aria-label` معنادار دارد تا معنی مقدار روی hover و برای ابزارهای دسترس‌پذیری روشن باشد.

## پاک‌سازی Quality Gate

خطاهای گزارش‌شده توسط ESLint/React Compiler در این بخش‌ها اصلاح شدند:

- حذف `setState` همگام از Effectهای تاریخ، تم، سایدبار، فیلتر بازه و Product Tour.
- جایگزینی خواندن state خارجی با `useSyncExternalStore` در media query، hydration، سایدبار و فیلتر تاریخ.
- حذف mutation حین render در `AllocationDonut`.
- جایگزینی `react-hook-form.watch()` با `useWatch()` در فرم‌های مرتبط.
- شکستن صفحه تنظیمات به کارت‌های مستقل تا form/refها در render از یک manager آلوده به ref عبور نکنند.
- رفع dependency ناقص در Dialog تراکنش و warning پیکربندی PostCSS.

## Verification

- تست pure برای معنی `امنیت + رشد` اضافه شد.
- `check:lines`، `check:ui`، `check:regressions` و تست‌های Node در محیط بسته اجرا می‌شوند.
- `npm run check` کامل همچنان باید در محیطی که dependencyهای پروژه نصب هستند اجرا شود.
