# v0.30.0 — Market provider production reliability

این فاز معماری Providerهای بازار را بدون تغییر مدل Local-First یا افزودن داده ساختگی، برای خطاهای واقعی Production سخت‌سازی می‌کند.

## Provider health and safe failures

- `lib/market/reliability.ts` یک مدل مشترک برای Health هر Provider اضافه می‌کند: `ok`، `degraded`، `unavailable`، `unconfigured` و `idle`.
- Failureها به کدهای پایدار مثل `timeout`، `rate_limited`، `blocked`، `unauthorized`، `invalid_response` و `network` طبقه‌بندی می‌شوند.
- Routeهای بازار دیگر متن خام Body/Error سرویس بیرونی را به کاربر برنمی‌گردانند؛ UI فقط پیام امن و از پیش تعریف‌شده می‌بیند.
- پاسخ Quote/Search/History متادیتای Health را برمی‌گرداند تا Client بتواند بین «کاملاً سالم» و «داده زنده ولی ناقص» تفاوت بگذارد.

## Bounded provider execution

- BrsApi و Tindex timeout سروری کوتاه و مشخص دارند.
- هر Instance از TSETMC یک Budget کلی و timeout هر Request دارد؛ بنابراین Portfolio بزرگ نمی‌تواند یک refresh را با زنجیره طولانی Requestها برای مدت نامحدود نگه دارد.
- Quoteهای مستقل BrsApi، TSETMC و اتصال‌های legacy Tindex در مرحله اول موازی اجرا می‌شوند.
- Tindex core fallback فقط وقتی BrsApi واقعاً یکی از USD/Gold/BTC را کم دارد اجرا می‌شود؛ برای حفظ سهمیه رایگان، بدون نیاز فراخوانی نمی‌شود.
- اتصال‌های قدیمی Tindex همچنان محدود و سازگار باقی می‌مانند و Migration اجباری ندارند.

## Client behavior

- `useMarket` Health آخرین refresh را نگه می‌دارد و همچنان در نبود Quote تازه به Snapshot واقعی IndexedDB برمی‌گردد.
- Market refresh در Topbar/Mobile وضعیت «live»، «offline»، «unconfigured» و «degraded» را واضح‌تر در Tooltip/Label بیان می‌کند.
- Dashboard در حالت `live + degraded` صریحاً می‌گوید بعضی منابع ناقص‌اند، به‌جای اینکه همه Providerها را سالم فرض کند.
- قیمت دستی، Cost-basis fallback و Snapshot محلی همان رفتار قبلی را دارند؛ هیچ Quote یا History مصنوعی تولید نمی‌شود.

## Release invariants

- IndexedDB schema همچنان `6` است؛ Migration داده‌ای وجود ندارد.
- Service Worker cache به `poolamkoo-v54` افزایش یافته است.
- `BRS_API_KEY` همچنان Provider اصلی نرخ‌های عمومی است.
- TSETMC برای سهام/ETF جدید بدون API Key باقی می‌ماند.
- `TINDEX_API_TOKEN` همچنان کاملاً اختیاری و فقط legacy/emergency/history است.
- Background Push همچنان پیش‌فرض خاموش است.
