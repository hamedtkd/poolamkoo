# Poolamkoo v0.37.0 — Safe asset archive lifecycle

این نسخه آرشیو دارایی را از یک «پنهان‌کردن ساده» به یک چرخه امن و قابل‌بازگشت تبدیل می‌کند.

## چه تغییر کرد؟

- دارایی دارای موجودی باز دیگر قابل آرشیو نیست؛ چون پنهان‌شدن آن می‌تواند ارزش واقعی سبد را کمتر از واقع نشان دهد.
- اگر یک آیتم برنامه مالی هنوز مبلغ انجام‌نشده‌ای برای همان دارایی داشته باشد، آرشیو تا تعیین‌تکلیف برنامه مسدود می‌شود.
- دارایی‌های آرشیوشده در صفحه سرمایه‌گذاری قابل مشاهده و بازگردانی هستند و قبل از Restore یک Recovery Snapshot محلی ساخته می‌شود.
- داده‌های قدیمی که پیش از این نسخه با موجودی باز آرشیو شده‌اند از محاسبه ارزش سبد حذف نمی‌شوند؛ تا زمان بازگردانی همچنان برای valuation و دریافت quote مرتبط در نظر گرفته می‌شوند.
- گزارش‌ها و جدول تاریخچه نام دارایی آرشیوشده را حفظ می‌کنند و دیگر آن را «دارایی حذف‌شده» تلقی نمی‌کنند.
- دارایی آرشیوشده با موجودی باز در UI به‌عنوان وضعیت نیازمند بازگردانی مشخص می‌شود؛ اما برای تصمیم تخصیص هدف و پول جدید، فقط دارایی‌های فعال وارد محاسبه می‌شوند.

## مرزهای نسخه

- هیچ دارایی یا تراکنشی در عملیات Archive حذف نمی‌شود.
- Hotfix پیش از انتشار: اکشن تأیید آرشیو حالا `disabled` را به‌صورت رسمی در wrapper مشترک AlertDialog پشتیبانی می‌کند؛ در نتیجه حالت‌های مسدودشده هم از نظر TypeScript و هم در UI واقعاً غیرقابل تأیید هستند.
- Hotfix پیش از انتشار: لیست `allAssets` حالا از نتیجه Dexie با `useMemo` پایدار می‌شود تا فیلترهای Active/Archived dependency ثابت داشته باشند و lint بدون warning باقی بماند.
- IndexedDB همچنان schema 7 است و migration جدیدی ندارد.
- Backup/Restore، Device Transfer، Provider priority و Background Push تغییری نکرده‌اند.
- Service Worker cache در این نسخه `poolamkoo-v61` است.
