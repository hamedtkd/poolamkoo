# v0.24.0 — Portfolio decision UX and PWA entry hardening

این نسخه دو مرز محصول را شفاف‌تر می‌کند: تصمیم‌گیری درباره ترکیب واقعی سبد و جداسازی Landing عمومی از PWA نصب‌شده.

## Portfolio decision UX

- برای هر دارایی، سهم فعلی سبد از ارزش واقعی همان دارایی نسبت به کل سبد محاسبه و کنار `targetPct` ذخیره‌شده کاربر نمایش داده می‌شود.
- مدل خالص `lib/portfolio-allocation.ts` مقدار هدف، فاصله درصدی، فاصله ارزشی و وضعیت «کمتر از هدف / نزدیک هدف / بیشتر از هدف / بدون هدف» را محاسبه می‌کند.
- محدوده «نزدیک هدف» برابر ۱ واحد درصد است و در تست‌ها ثابت شده تا رفتار UI به قانون پنهان وابسته نباشد.
- «اولویت بررسی برای پول جدید» فقط وقتی نمایش داده می‌شود که جمع هدف‌ها عملاً ۱۰۰٪ باشد؛ این بخش فقط کمبود نسبت به هدف خود کاربر را مرتب می‌کند و توصیه خرید/فروش یا پیش‌بینی بازار نیست.
- اگر یک داراییِ موجود قیمت بازار یا قیمت دستی قابل اتکا نداشته باشد و ارزش آن فقط با fallback بهای خرید نمایش داده شود، مرور ترکیب به‌صراحت ناقص علامت می‌خورد.
- جدول دارایی در دسکتاپ و کارت موبایل سهم فعلی، سهم هدف و وضعیت فاصله را نشان می‌دهد.
- هیچ Chart library، API بازار، مدل پیش‌بینی، سفارش خودکار یا داده مصنوعی جدیدی اضافه نشده است.

## PWA / Landing boundary

- `app/manifest.ts` سراسری حذف و Manifest نصب‌شونده به `public/app.webmanifest` منتقل شد.
- Manifest دارای `id` و `start_url` برابر `/dashboard` است و فقط از layout مسیرهای `(workspace)` advertise می‌شود.
- `appleWebApp` نیز از Root metadata به Workspace منتقل شد تا Landing عمومی سطح نصب اپ نباشد.
- `PwaUpdateNotice` و در نتیجه رجیستر شدن Service Worker دیگر از `Providers` سراسری اجرا نمی‌شود و فقط داخل Workspace mount می‌شود.
- `/` از explicit precache سرویس‌ورکر حذف شد؛ `/dashboard` و `/offline` باقی مانده‌اند و cache به `poolamkoo-v40` ارتقا یافت.
- برای نصب‌های قدیمی یا مرورگرهایی که URL ریشه را در حالت standalone بازیابی می‌کنند، Landing فقط در حالت standalone و فقط روی `/` به `/dashboard` می‌رود؛ بازدید عادی وب همچنان Landing را می‌بیند.
- Update flow صریح نسخه‌های قبل (`waiting` → تأیید کاربر → `SKIP_WAITING` → `controllerchange`) بدون تغییر حفظ شده است.

## Data safety / privacy

- IndexedDB schema همچنان **6** است و Migration جدیدی وجود ندارد.
- Backup/Restore و Device Transfer format تغییر نکرده‌اند.
- هیچ داده مالی جدیدی به Server یا Analytics ارسال نمی‌شود.
- Background Push همچنان آزمایشی و به‌صورت پیش‌فرض خاموش است.
