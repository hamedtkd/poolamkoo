# v0.28.0 — Market provider resilience

این نسخه وابستگی مسیر بورس تهران به سهمیه بسیار محدود Tindex را حذف می‌کند و Providerها را بر اساس نوع داده جدا می‌کند.

## معماری جدید بازار

- سهام و ETFهای جدید مستقیماً از `cdn.tsetmc.com` و فقط از Routeهای Server-side پولم‌کو دریافت می‌شوند.
- جست‌وجوی نماد از `Instrument/GetInstrumentSearch`، قیمت روز از `ClosingPrice/GetClosingPriceInfo` و تاریخچه روزانه از `ClosingPrice/GetClosingPriceDailyList` می‌آید.
- قیمت‌های TSETMC که ریال هستند قبل از ورود به مدل مالی داخلی به تومان تبدیل می‌شوند.
- TSETMC به API Key نیاز ندارد. Endpointها عمومی ولی غیررسمی/بدون SLA هستند؛ قطع یا Block شدن آن‌ها باید با Snapshot واقعی و قیمت دستی تحمل شود.
- BrsApi منبع اصلی دلار، طلای ۱۸ عیار، بیت‌کوین و تتر باقی می‌ماند و درخواست آن ۶۰ ثانیه در Server Data Cache مشترک می‌شود.
- Tindex دیگر Provider پیش‌فرض بورس نیست. توکن آن اختیاری است و فقط برای اتصال‌های Legacy، fallback آهسته نرخ‌های پایه و تاریخچه اختیاری دلار/طلا حفظ شده است.
- fallback عمومی Tindex به‌دلیل محدودیت پلن رایگان ۳۰ دقیقه cache می‌شود و Quoteهای Legacy نیز عمداً بسیار محافظه‌کارانه cache می‌شوند.

## داده واقعی، بدون جعل

- هیچ Quote یا تاریخچه مصنوعی ساخته نمی‌شود.
- اگر Provider خارجی در دسترس نباشد، آخرین `marketSnapshots` واقعی دستگاه و سپس قیمت دستی دارایی همچنان fallback هستند.
- TSETMC مستقیم فقط InsCode عمومی نماد را می‌بیند؛ درآمد، موجودی صندوق، مقدار سبد یا تراکنش‌های کاربر به Provider بازار ارسال نمی‌شوند.
- تاریخچه TSETMC یک ساعت cache می‌شود و قیمت لحظه‌ای کوتاه‌مدت cache دارد تا چند کاربر یا چند Route بی‌دلیل upstream را تکرار نکنند.

## سازگاری با داده‌های قبلی

- IndexedDB همچنان schema `6` است؛ Migration مخرب نداریم.
- دارایی‌ها، دیده‌بان‌ها و هشدارهایی که قبلاً `source: "tindex"` داشته‌اند حذف یا تغییر خودکار نمی‌شوند.
- برای این اتصال‌های قدیمی، Tindex به‌صورت محدود حفظ می‌شود. کاربر می‌تواند هر زمان از ویرایش دارایی/دیده‌بان همان نماد را دوباره با TSETMC لینک کند.
- هشدارهای جدید TSETMC داخل اپ با refresh قیمت کار می‌کنند. Background Push همچنان Backlog/خاموش است و در این نسخه فعال نشده است.

## چرا Gheymat.online / PersianToolbox / StreamData / Arzhaam فعلاً Provider اصلی نشدند؟

- Gheymat.online سقف رایگان مناسب‌تری دارد، اما قرارداد دقیق endpoint/auth پاسخ Swagger باید قبل از پیاده‌سازی production به‌صورت مستقیم تأیید شود؛ adapter حدسی اضافه نشده است.
- PersianToolbox خودش تضمین نمی‌کند نرخ ارز، نرخ بازار آزاد ایران باشد؛ بنابراین برای دلار اصلی پولم‌کو مناسب نیست.
- StreamData پوشش و Rate Limit جذابی دارد، اما دریافت Token از مسیر تماس انجام می‌شود و در مستندات عمومی فعلی تعهدی برای پلن رایگان دائمی ندیدیم؛ بنابراین وابستگی پیش‌فرض یک پروژه صفرهزینه نیست.
- آدرس `arzhaam.ir` در بررسی فعلی به مستندات سرویس نامرتبط BananaAI تغییر کرده است؛ بنابراین اطلاعات قدیمی API بازار Arzhaam را قابل اتکا ندانستیم و هیچ Adapter حدسی برای آن اضافه نشد.

## Release safety

- `MarketSource` حالا `tsetmc` را می‌شناسد و Attribution در UI نمایش داده می‌شود.
- تست‌های parser برای Search، Quote، تغییر روزانه، تبدیل ریال→تومان و OHLC تاریخچه اضافه شدند.
- Regression gate تضمین می‌کند Search و Quote جدید بورس به TSETMC مستقیم وابسته باشند و Tindex دوباره به Provider پیش‌فرض تبدیل نشود.
