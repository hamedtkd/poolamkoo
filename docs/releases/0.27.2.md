# v0.27.2 — Critical content visibility hotfix

این نسخه دومین Hotfix پایداری UI در چرخه v0.27 است و دو Regression مرتبط را می‌بندد: Dashboard خالی در صفحه اصلی و Dialogهایی که فقط قاب/دکمه بستن را نشان می‌دادند.

## ریشه مشکل

`MotionReveal` در Dashboard و wrapper داخلی `DialogContent` محتوای واقعی را قبل از Hydration با `opacity: 0` رندر می‌کردند. اگر اجرای Motion در مرورگر دیر می‌شد یا transition به هر دلیل کامل نمی‌شد، Shell و Overlay باقی می‌ماندند اما محتوای مالی/فرم عملاً نامرئی بود. Refresh می‌توانست وضعیت را موقتاً درست کند.

## اصلاح

- Dashboard/Card reveal دیگر هرگز با opacity صفر شروع نمی‌شود.
- Dialogهای مشترک نیز بدنه فرم را transparent نمی‌کنند؛ فقط translate/scale نرم باقی مانده است.
- Reduced Motion همچنان رعایت می‌شود.
- Route-level wrapper همان div پایدار v0.27.1 باقی مانده است.
- Browser Release Smoke به حالت `no-preference` تغییر کرده تا مسیر کاربران دارای Motion عادی را پوشش دهد.
- تست مرورگر Dashboard را از نظر visibility واقعی بررسی می‌کند، Modal «پول جدید دارم» را باز می‌کند، بدنه آن را Assert می‌کند و سپس Navigation داخلی Reports/Settings را ادامه می‌دهد.
- Regression test سورس اجازه بازگشت `opacity: 0` به MotionReveal یا بدنه Dialog را نمی‌دهد.

## Data safety

- IndexedDB schema همچنان 6 است.
- هیچ migration، تغییر Backup، Market provider یا telemetry جدیدی وجود ندارد.
- Service Worker cache به `poolamkoo-v47` افزایش یافته است.
