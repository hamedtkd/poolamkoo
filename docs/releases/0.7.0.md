# v0.7.0 — ورود امن سوابق سرمایه‌گذاری

## هدف نسخه

کاربری که قبل از پولم‌کو سرمایه‌گذاری داشته نباید مجبور باشد ده‌ها خرید و فروش قدیمی را یکی‌یکی ثبت کند. این نسخه ورود دسته‌ای سابقه سرمایه‌گذاری را با **CSV + پیش‌نمایش + اعتبارسنجی قبل از ثبت** اضافه می‌کند.

## Historical Import

در صفحه «سرمایه‌گذاری‌ها» دکمه **ورود سوابق CSV** اضافه شده است.

فایل می‌تواند این ستون‌ها را داشته باشد:

- دارایی / `asset`
- نماد / `symbol` — اختیاری ولی برای Match دقیق‌تر مفید است
- نوع / `type` — خرید یا فروش؛ اگر ستون وجود نداشته باشد، خرید فرض می‌شود
- مقدار / `quantity`
- قیمت واحد تومان / `unit_price_toman`
- تاریخ / `date`
- یادداشت / `note` — اختیاری

عنوان ستون‌ها هم به فارسی و هم انگلیسی پذیرفته می‌شوند. اعداد فارسی/عربی نیز نرمال می‌شوند.

## تاریخ شمسی و میلادی

تاریخ‌های زیر مستقیماً قابل استفاده‌اند:

- `1405/03/01`
- `۱۴۰۵/۰۳/۰۱`
- `2026-05-22`

تاریخ آینده یا تاریخ نامعتبر قبل از Import متوقف می‌شود.

## پیش‌نمایش و محافظت از داده

قبل از ثبت نهایی، هر ردیف یکی از سه وضعیت را می‌گیرد:

- **آماده ثبت**
- **تکراری** — قبلاً ثبت شده یا در همان فایل تکرار شده و دوباره ذخیره نمی‌شود
- **نیاز به اصلاح** — مثلاً دارایی پیدا نشده، مقدار/قیمت نامعتبر است یا فروش از موجودی همان تاریخ بیشتر است

تا زمانی که ردیف نامعتبر وجود داشته باشد ثبت نهایی غیرفعال می‌ماند.

## ساخت دارایی بدون خروج از Import

اگر دارایی فایل در پولم‌کو وجود نداشته باشد، نام آن نمایش داده می‌شود و کاربر می‌تواند از همان مودال **دارایی جدید** بسازد. نام دارایی گمشده از قبل داخل فرم ساخت قرار می‌گیرد و بعد از ذخیره، پیش‌نمایش فایل بدون انتخاب مجدد فایل دوباره Resolve می‌شود.

این ادامه همان قانون UX نسخه 0.6.0 است: جریان اصلی نباید برای ساخت موجودیت مرتبط شکسته شود.

## قالب نمونه

از خود مودال می‌توان یک CSV نمونه UTF-8 دانلود کرد. فایل‌های CSV خروجی Excel/Google Sheets نیز با جداکننده‌های comma، semicolon و tab خوانده می‌شوند.

## محدودیت‌های آگاهانه

- Import این فاز برای **خرید/فروش سرمایه‌گذاری** است؛ درآمدها، صندوق‌های هدف و برنامه‌های پول عمداً وارد این قالب نشده‌اند.
- قیمت دارایی‌های دستی بعد از Import با قیمت تاریخی بازنویسی نمی‌شود؛ قیمت فعلی همچنان جداگانه توسط کاربر کنترل می‌شود.
- در هر بار حداکثر ۲۰۰۰ ردیف و فایل ۲ مگابایتی پذیرفته می‌شود.

## Quality

- تست تبدیل تاریخ شمسی، اعداد فارسی، Match با symbol، Duplicate detection، Oversell validation و تبدیل به مدل canonical تراکنش اضافه شد.
- Import Preview از `DataTable` مشترک استفاده می‌کند و معماری UI را دور نمی‌زند.
