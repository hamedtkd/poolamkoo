# v0.16.0 — Open-source product surface

این نسخه مسیرهای اعتماد، راهنما و مشارکت متن‌باز را وارد خود محصول می‌کند؛ بدون اضافه‌کردن حساب کاربری، سرویس پولی یا Analytics.

## GitHub و جامعه

- لینک مستقیم مخزن `hamedtkd/poolamkoo` در Sidebar، منوی موبایل و Settings.
- نمایش تعداد Star با API عمومی GitHub و Cache سروری ۶ ساعته؛ GitHub token برای استفاده معمول لازم نیست.
- لینک گزارش مشکل، Security، MIT License و پروفایل Maintainer در صفحات عمومی.

## صفحات عمومی

- `/guide`: گردش کار اصلی پول جدید، صندوق، اجرا، سرمایه‌گذاری، انتقال و Backup.
- `/about`: فلسفه Local-first، متن‌باز بودن، منابع بازار و محدودیت توصیه مالی.
- `/privacy`: سیاست داده دقیق، درخواست‌های شبکه، GitHub stars، WebRTC و خاموش بودن Analytics در این نسخه.
- `/data-safety`: تفاوت Backup مستقل، Recovery Snapshot و انتقال دستگاه‌به‌دستگاه.
- `/security`: مدل امنیت Local-first، Secretها، Backup و گزارش مسئولانه.
- `/license`: خلاصه مجوز MIT با لینک به متن کامل مخزن.

این صفحه‌ها بیرون از AppRouteLayout هستند تا حتی قبل از تکمیل Onboarding هم قابل مشاهده باشند.

## حمایت کم‌مزاحمت

- روز استفاده واقعی به‌صورت محلی در `appMeta` ثبت می‌شود؛ روز تکراری دوباره شمرده نمی‌شود.
- Prompt حمایت فقط بعد از حداقل ۷ روز فعال متمایز و فقط روی Dashboard ظاهر می‌شود.
- گزینه‌ها: Star در GitHub، حمایت اختیاری Daramet، یا «فعلاً نه».
- «فعلاً نه» ۶۰ روز cooldown دارد؛ اقدام GitHub/Support تا ۱۸۰ روز Prompt را عقب می‌اندازد.
- حمایت مالی هیچ قابلیت محصولی را باز نمی‌کند.
- متادیتای Prompt دستگاهی است و وارد Backup مالی نمی‌شود.

## Zero-cost / Privacy

- هیچ dependency یا Backend پولی جدیدی اضافه نشده است.
- Analytics هنوز فعال نشده و به v0.18 موکول است.
- Background Push همچنان در Backlog و Build عادی خاموش است.
