# v0.3.2 — Navigation, responsive date filters, and build hardening

## Navigation and mobile UX

- The brand logo is now a home link in both desktop and mobile navigation.
- Desktop sidebar focuses only on navigation, search, and the primary new-money action.
- Market refresh, privacy, theme, guide, current Persian date, and time filter moved to a dedicated desktop top bar.
- The mobile quick menu is denser and better grouped, while the bottom navigation uses a stronger glass surface for readability.
- Mobile Drawer supports swipe-down dismissal from its drag handle.

## Persian date and global filtering

- Added a responsive Persian date-range filter with quick presets.
- Desktop uses Popover and mobile uses Drawer presentation.
- The header shows today's Persian date.
- Incoming-money, dashboard event metrics, and reports respect the shared selected time range.
- Current portfolio positions intentionally continue to use the complete transaction history so a date filter cannot corrupt current holdings.

## Production build fixes

- TanStack Table v9 pagination now reads the core table store instead of React-only `table.state` on the generic table instance.
- New-money persistence explicitly guards Dexie-generated income IDs before using them as required foreign keys.
- Allocation form watch values are normalized to concrete numeric values before calculations.

## Validation

- Unit tests include Persian date-range boundary behavior.
- UI architecture, regression checks, source line limits, and TypeScript syntax parsing are part of the release verification flow.
