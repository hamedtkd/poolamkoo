# v0.28.1 — Hybrid motion restoration

این نسخه یک اصلاح انتشار برای v0.28 است و مدل هیبریدی انیمیشن را تثبیت می‌کند.

## تغییرات

- dependency رسمی `motion` دوباره به پروژه برگشت؛ حذف کامل آن تصمیم درستی نبود چون برای انیمیشن‌های viewport/scroll در Landing و تعامل‌های آینده مفید است.
- `tailwindcss-animated` همچنان موتور اصلی entranceهای Workspace است: هر آیتم با delay مستقل و direction مناسب وارد می‌شود و کل Route هیچ animation سراسری ندارد.
- `MotionReveal` جدید فقط برای بخش‌های Landing که هنگام Scroll وارد viewport می‌شوند استفاده می‌شود؛ Hero حیاتی همچنان بدون وابستگی به Motion hydration قابل مشاهده است.
- Motion در Providers سراسری import نمی‌شود تا Workspace مجبور به دانلود runtime آن نباشد؛ bundle فقط در جایی که MotionReveal واقعاً استفاده شده split می‌شود.
- `prefers-reduced-motion` در هر دو مسیر CSS و Motion رعایت می‌شود.
- فایل `components/motion/reveal.tsx` دوباره بخشی از Source است تا Full-source replacement فایل قدیمی ناسازگار با dependency حذف‌شده باقی نگذارد.
- نسخه برنامه `0.28.1` و Service Worker cache برابر `poolamkoo-v51` است.

## بدون تغییر

- IndexedDB schema همچنان 6 است.
- معماری TSETMC/BrsApi/Tindex نسخه 0.28 بدون تغییر باقی مانده است.
- Backup/restore/device transfer تغییری ندارند.
- Background Push همچنان به‌صورت پیش‌فرض خاموش است.
