# v0.13.1 — Zero-cost local-first baseline

این نسخه Background Web Push را از مسیر عمومی محصول خارج می‌کند تا پولم‌کو بدون Redis، Cron یا هزینه زیرساخت اضافه قابل Deploy باقی بماند.

## چه چیزی تغییر کرد؟

- `vercel.json` دیگر هیچ Cronای زمان‌بندی نمی‌کند.
- UI فعال‌سازی Push در Build عادی نمایش داده نمی‌شود.
- Hook کلاینت در حالت پیش‌فرض هیچ درخواست Push/Redis نمی‌زند و Permission درخواست نمی‌کند.
- APIهای Push و Cron فقط با Feature Flag آزمایشی صریح قابل استفاده‌اند.
- `.env.example` فقط تنظیمات عادی بازار را نگه می‌دارد؛ Push برای Deploy معمول هیچ Secretی نمی‌خواهد.
- کد v0.13.0 حذف نشده و همراه تست‌ها در Repository باقی مانده است.

## Feature flag آزمایشی

برای پژوهش محلی در آینده، `.env.push.example` وجود دارد و نیازمند `NEXT_PUBLIC_EXPERIMENTAL_BACKGROUND_PUSH=1` است. حتی در این حالت Scheduler به‌صورت پیش‌فرض همراه پروژه Deploy نمی‌شود.

## Roadmap جدید

بر اساس اولویت Local-First و تجربه پروژه Saatyar، فازهای بعدی روی ماندگاری داده، Backup، انتقال مستقیم بین دستگاه‌ها، سطح Open Source/Support، Motion و Analytics رایگان متمرکز می‌شوند. جزئیات در `docs/ROADMAP.md` است.
