# v0.15.0 — Simple device transfer

این نسخه انتقال Local-First بین دو دستگاه را اضافه می‌کند و Warning باقی‌مانده v0.14.0 را نیز تمیز می‌کند.

## Direct transfer

- انتقال مستقیم WebRTC بدون حساب کاربری، Redis، Cron یا Backend مالی.
- Pairing با کد اتصال قابل Copy/Share و کد پاسخ دستگاه مقصد.
- رمز یک‌بارمصرف ۶ کاراکتری برای AES-GCM روی Payload، علاوه بر رمزنگاری DTLS خود WebRTC.
- Chunked transfer با progress و SHA-256 integrity verification.
- Preview تعداد پول‌های ورودی، صندوق‌ها، دارایی‌ها، تراکنش‌ها، کارت‌های برنامه، دیده‌بان و هشدارها قبل از Import.
- Import صریح و Replace-only برای جلوگیری از duplicate ID/transaction.
- Recovery Snapshot خودکار قبل از جایگزینی داده دستگاه مقصد.
- acknowledgement دریافت و Import برای اینکه دستگاه فرستنده پایان واقعی انتقال را بداند.
- timeout بعد از مرحله نهایی Pairing و Retry از همان Dialog.

## Zero-cost fallback

اگر WebRTC برقرار نشود، Backup رمزنگاری‌شده فایل همچنان fallback عمومی انتقال است. هیچ سرویس ابری جدیدی برای v0.15 لازم نیست.

## Quality

Warning `react-hooks/exhaustive-deps` در `use-backup-safety` با وابستگی پایدار `metaQuery` رفع شد و هیچ Ruleی خاموش نشده است.
