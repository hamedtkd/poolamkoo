# v0.14.0 — Data Safety & Recovery

این نسخه ماندگاری داده را به یک قابلیت قابل مشاهده و قابل کنترل تبدیل می‌کند؛ بدون ساخت حساب کاربری یا فرستادن داده مالی به سرور.

## Backup health

- زمان آخرین دانلود موفق بکاپ روی همان دستگاه ثبت می‌شود.
- بعد از شکل‌گیری داده واقعی، اگر کاربر هنوز بکاپ نگرفته باشد یادآوری دوستانه نمایش داده می‌شود.
- بکاپ‌های قدیمی‌تر از ۷ روز دوباره یادآوری می‌شوند.
- کاربر می‌تواند یادآوری را ۳ روز عقب بیندازد.
- یادآوری در Onboarding یا وقتی داده مهمی وجود ندارد نمایش داده نمی‌شود.

## Encrypted backup download

- دانلود بکاپ از یک مسیر مشترک و با Error Handling کامل انجام می‌شود.
- مسیر سریع یادآوری، بکاپ رمزنگاری‌شده AES-GCM می‌سازد.
- Settings همچنان اجازه بکاپ رمزنگاری‌شده یا بدون رمز را می‌دهد.
- رمز بکاپ هیچ‌وقت در IndexedDB یا تنظیمات ذخیره نمی‌شود.
- موفقیت و خطا با Toast قابل مشاهده گزارش می‌شوند.

## Local recovery history

- IndexedDB schema به v6 ارتقا یافت و `recoverySnapshots` و `appMeta` اضافه شدند.
- حداکثر ۵ نقطه بازیابی محلی نگه داشته می‌شود.
- هنگام استفاده واقعی، حداکثر روزی یک Snapshot خودکار ایجاد می‌شود.
- قبل از Restore فایل بکاپ، حذف پول ورودی، حذف صندوق، حذف تراکنش سرمایه‌گذاری، حذف کارت برنامه و آرشیو دارایی Snapshot ساخته می‌شود.
- کاربر می‌تواند از Settings نقطه دستی بسازد یا یکی از نسخه‌های اخیر را بازگرداند.
- پیش از بازگردانی Snapshot نیز از وضعیت فعلی یک Snapshot جدید ساخته می‌شود.

## Storage durability

- وضعیت Persistent/Best-effort مرورگر در صفحه Backup توضیح داده می‌شود.
- Snapshotهای محلی صریحاً به‌عنوان Recovery معرفی می‌شوند و هرگز جای Backup فایل معرفی نمی‌شوند.
- متادیتای دستگاه و Recovery history داخل فایل Backup صادر نمی‌شوند تا داده اصلی از state محلی دستگاه جدا بماند.

## PWA

Service Worker cache به `poolamco-v27` ارتقا یافت.
