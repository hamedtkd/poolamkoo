# Poolamkoo 0.34.0 — Persisted provider-scoped market identity

این نسخه کاری را که v0.33 در runtime/decision layer شروع کرده بود تا لایه ماندگار IndexedDB ادامه می‌دهد.

## چه تغییر کرد؟

- `marketWatchlist` دیگر `marketId` خام را به‌تنهایی unique نمی‌داند؛ هویت ماندگار آن `source + marketId` است.
- `marketAlerts` نیز compound index روی `source + marketId` دارد تا هشدارهای دو Provider با شناسه خام مشابه با هم قاطی نشوند.
- Merge سمت سرور، dedupe درخواست‌های کلاینت، Snapshot runtime و انتخاب نمودار همگی از همان provider-scoped identity استفاده می‌کنند؛ حتی اگر TSETMC و Tindex یک `marketId` خام یا symbol مشابه داشته باشند.
- افزودن دوباره یک نماد به Watchlist و تشخیص هشدار تکراری از همان compound identity استفاده می‌کند.
- کلیدهای UI برای Watchlist/detail dialog و Notification tag هم Provider را در هویت نگه می‌دارند.
- دارایی‌های legacy که `marketId` دارند ولی `marketSource` قدیمی/خالی است، در migration به `tindex` نرمال می‌شوند؛ چون لینک‌های قدیمی قبل از TSETMC مستقیم فقط از مسیر Tindex ساخته می‌شدند.
- Watchlist/Alert قدیمی با `source` خالی نیز در migration به Tindex نرمال می‌شوند. رکوردهای صریح TSETMC دست‌نخورده می‌مانند.
- Restore/Recovery/Device Transfer داده قدیمی را قبل از persistence با همان قاعده نرمال می‌کند و Watchlist تکراری برای یک Provider را قبل از destructive replacement رد می‌کند.
- Backupهای schema 6 و قدیمی‌تر همچنان به‌عنوان `older` قابل خواندن‌اند؛ فایل ساخته‌شده با schema جدیدتر همچنان قبل از clear/import رد می‌شود.

## Schema migration

- IndexedDB از schema 6 به **schema 7** می‌رود.
- نسخه 6 صریحاً در زنجیره Dexie باقی مانده تا upgrade کاربران موجود یک migration واقعی 6 → 7 باشد.
- نام دیتابیس (`poolyar-local`)، table names، primary keys و backup envelope format تغییر نکرده‌اند.
- هیچ داده مالی به سرور منتقل نمی‌شود و migration فقط روی Browser Storage همان دستگاه انجام می‌شود.

## مرزهای ثابت

- BrsApi همچنان core primary است.
- TSETMC همچنان exchange primary برای لینک‌های جدید است.
- Tindex همچنان legacy/emergency fallback است.
- Snapshot و cost-basis همچنان فقط continuity نمایشی‌اند و تصمیم خودکار را هدایت نمی‌کنند.
- هیچ قیمت، NAV، تاریخچه یا پیش‌بینی ساختگی تولید نمی‌شود.
- Background Push همچنان experimental/backlog و خاموش به‌صورت پیش‌فرض است.
- dependency جدیدی اضافه نشده است.
