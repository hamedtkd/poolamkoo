# v0.24.1 — Release hardening, canonical identity, and product media

این Patch خطای Release Candidate v0.24.0 را قبل از انتشار اصلاح و ابزار رسانه محصول را اضافه می‌کند.

## اصلاح Release blocker

- Import نامعتبر `RiScaleLine` با Export واقعی `RiScalesLine` جایگزین شد تا TypeScript و Turbopack Build روی `react-icons` پاس شوند.
- Quality gate جدید `check:icons` همه Named Importهای `react-icons/ri` را با Exportهای نصب‌شده مقایسه می‌کند تا این کلاس خطا زودتر و با پیام واضح متوقف شود.

## نام استاندارد پروژه

- نام لاتین canonical پروژه در Package، مستندات و شناسه‌های فعال Runtime به **Poolamkoo / poolamkoo** یکسان شد.
- Repository رسمی همچنان `https://github.com/hamedtkd/poolamkoo` است.
- نام فایل‌های خروجی Backup/CSV، Service Worker cache/tag، User-Agent و شناسه‌های UI فعال از `poolamkoo` استفاده می‌کنند.
- دو شناسه داده‌ای قدیمی `poolyar-local` و `poolyar-backup` عمداً تغییر نکرده‌اند، چون تغییر آن‌ها می‌تواند IndexedDB موجود و Backupهای قبلی را از کاربران جدا کند.
- Decoder انتقال مستقیم، کدهای Pairing نسل قبلی و canonical جدید را می‌پذیرد ولی کد جدید را با شناسه Poolamkoo تولید می‌کند.

## Product media

- `npm run media:capture` از Production Build واقعی و یک Browser Profile موقت اسکرین‌شات می‌سازد.
- `npm run media:capture:built` همان Capture را روی Build آماده اجرا می‌کند.
- Fixture فقط داده ساختگی مالی دارد و Profile واقعی کاربر را نمی‌خواند.
- درخواست Market API، Push و Cloudflare Web Analytics در Capture مسدود می‌شوند تا خروجی به Secret یا داده شبکه وابسته نباشد.
- Workflow دستی GitHub Actions با نام **Product media** خروجی PNGها را در Artifact `poolamkoo-product-screenshots` قرار می‌دهد و خودش Repository را Commit نمی‌کند.

## PWA / data safety

- مرز PWA نسخه v0.24 حفظ شده: Landing عمومی `/` PWA را advertise/register نمی‌کند و Workspace Manifest از `/dashboard` شروع می‌شود.
- Service Worker cache به `poolamkoo-v41` ارتقا یافت.
- IndexedDB schema همچنان **6** است و Migration داده نداریم.
