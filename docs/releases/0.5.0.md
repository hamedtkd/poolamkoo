# v0.5.0 — تکمیل UI و پشتیبانی اولیه بورس

## هدف نسخه

بستن ایرادهای بصری باقی‌مانده از بازطراحی و شروع فاز بعدی سرمایه‌گذاری با اضافه‌کردن سهام/بورس به‌عنوان یک نوع دارایی مستقل.

## تغییرات UI و UX

- نمودارهای `ArcGauge` در کل اپ به‌صورت حلقه کامل رندر می‌شوند؛ بخش خاکستری باقی‌مانده دیگر حذف نمی‌شود.
- کارت «قانون پول فعلی» در داشبورد با همان رفتار حلقه کامل آنبوردینگ هماهنگ شد.
- KPIهای داشبورد، گزارش‌ها، صندوق‌ها و سرمایه‌گذاری آیکون‌های معنایی‌تر و یک سیستم نمایشی یکدست دارند.
- رنگ آیکون KPI سود/زیان در وضعیت منفی به‌صورت هشدار نمایش داده می‌شود.
- Topbar دسکتاپ به بالای صفحه منتقل شد و ارتفاع آن دقیقاً با هدر لوگوی سایدبار هم‌تراز شد.
- اندازه لوگوی هدر سایدبار برای قرارگیری بصری بهتر در مرکز اصلاح شد.

## بورس و سهام

- `stock` به‌عنوان `AssetKind` مستقل اضافه شد.
- یک دارایی پیش‌فرض «سهام / بورس» با سهم هدف صفر برای کاربران فعلی و جدید در دسترس است.
- کاربر می‌تواند دارایی سهامی جدید با نام و نماد بورسی بسازد.
- قیمت سهام در این فاز دستی است و با هر خرید/فروش یا ویرایش دارایی قابل به‌روزرسانی است.
- موجودی قبلی سهام نیز مثل سایر دارایی‌ها به تراکنش تاریخی تبدیل می‌شود تا Cost Basis، ارزش فعلی و سود/زیان تجمیع شوند.
- صندوق سرمایه‌گذاری و دارایی سفارشی نیز در مسیر قیمت دستی قرار گرفتند؛ انتخاب نماد بازار نامرتبط برای آن‌ها حذف شد.

## تست و محافظت از Regression

- تست نوع دارایی جدید و رفتار قیمت دستی اضافه شد.
- Regression check برای حلقه کامل، هم‌ترازی Topbar، پشتیبانی سهام و آیکون‌های KPI تقویت شد.

## فاز بعدی

1. Historical Import با CSV و Preview/Validation قبل از ثبت.
2. Migration UX و گزارش ردیف‌های نامعتبر / Undo.
3. Provider واقعی قیمت بورس در صورت انتخاب منبع داده قابل‌اعتماد.
