# v1.1.1 — Investment queue UX & GitHub showcase

`v1.1.1` یک Patch تجربه‌کاربری و Presentation بعد از `v1.1.0` است. داده نمایشی کامل‌تر نشان داد که اگر چند پول ورودی هم‌زمان خریدهای سرمایه‌گذاری انجام‌نشده داشته باشند، بخش «خریدهای پیشنهادی» به یک دیوار بلند از کارت‌های تقریباً یک‌شکل تبدیل می‌شود. این نسخه همان قرارداد مالی را نگه می‌دارد اما صف خرید را فشرده و قابل اسکن می‌کند.

## تغییرات اصلی

- خریدهای انجام‌نشده به‌جای Card مستقل برای هر Asset/Income، بر اساس **پول ورودی** گروه‌بندی می‌شوند.
- جدیدترین گروه به‌صورت پیش‌فرض باز است و گروه‌های قدیمی بسته می‌مانند؛ در حالت عادی فقط چهار گروه جدید دیده می‌شوند و بقیه پشت «نمایش برنامه‌های قدیمی‌تر» قرار می‌گیرند.
- هر Group جمع باقی‌مانده، تعداد خریدهای باقی، تاریخ و درصد اجرای همان بخش رشد را نشان می‌دهد.
- داخل Group، هر خرید به یک Row فشرده با نام دارایی، مبلغ باقی‌مانده، Progress و Action «ثبت خرید» تبدیل شده است.
- Action هنوز دقیقاً همان `PlanItem` اصلی را به Transaction Dialog می‌دهد؛ بنابراین Link خرید به Income/Plan، Cost Basis و Execution sync تغییر نکرده‌اند.
- مقدارهای مالی این سطح با `SensitiveValue` علامت‌گذاری شده‌اند تا Privacy Mode همان رفتار بقیه Workspace را داشته باشد.
- GitHub README یک ویترین انگلیسی پنج‌تصویری WebP دارد: Overview، Income Planning، Funds & Goals، Reports & Insights و Settings & Themes.
- پنل‌های GitHub به‌صراحت Presentation معرفی شده‌اند و جای اسکرین‌شات واقعی Production را نمی‌گیرند؛ Capture واقعی همچنان در `docs/assets/screenshots/` باقی می‌ماند.
- نسخه‌های فارسی Presentation برای شبکه‌های اجتماعی خارج از Git نگه داشته می‌شوند تا Repository با Binaryهای تکراری سنگین نشود.
- رنگ سود و رشد قیمت از Accent انتخابی کاربر جدا شده و با Token معنایی **سبز** نمایش داده می‌شود؛ زیان و افت قیمت هم Token معنایی **قرمز** مستقل دارد. Label سود/زیان باز نیز بر اساس علامت مقدار به «سود باز» یا «زیان باز» تغییر می‌کند و مقدار علامت `+`/`−` صریح دارد.
- عددهای پولی به‌جای جداکننده فارسی `٬` که در فونت Mikhak بالاتر از خط پایه دیده می‌شود، رقم فارسی + comma استاندارد `,` دارند؛ همان Formatter در Money Input هم استفاده می‌شود.
- Hero لندینگ از حالت تیتر بسیار بزرگ + تصویر مفهومی خارج شده و به یک Composition سینمایی خواناتر با اسکرین‌شات واقعی موبایل، CTA واضح و حرکت Pointer بسیار محدود تبدیل شده است. متن نهایی کوتاه‌تر شده، اجزای Hero با stagger آرام از پایین وارد می‌شوند و Reveal سکشن‌ها از یک Spring نرم و یک جهت ثابت استفاده می‌کند تا حس «بازشدن از وسط» حذف شود. ایده سه‌بعدی نمونه حفظ شده ولی Scroll pin چند‌هزار پیکسلی وارد محصول نشده تا Landing روی موبایل و Reduced Motion آزاردهنده نشود.
- نمایش درصدهای علامت‌دار هم به Formatter مشترک منتقل شده است؛ تغییر روزانه بازار، بازده سبد، فاصله از هدف و NAV دیگر علامت `+`/`−` را به‌صورت موردی در Componentها نمی‌سازند.

## مرزهای ثابت

- IndexedDB همچنان **schema 8** است و migration داده نداریم.
- Allocation/Plan/Transaction semantics، Backup/Recovery/Device Transfer و Local-first ownership تغییر نکرده‌اند.
- Provider priority و quota hardening نسخه `v1.0.1` بدون تغییر باقی مانده‌اند.
- Settings architecture و Custom Theme نسخه `v1.1.0` حفظ شده‌اند.
- Service Worker cache برای دریافت Patch جدید به `poolamkoo-v71` می‌رود.

## Gate انتشار

قبل از Tag/Release باید `npm run check:stable` کامل سبز باشد. در مرور دستی، Investments را با چند Income دارای Growth Plan باز کن و روی Desktop/Mobile تأیید کن که صفحه دیگر با ده‌ها Card تکراری کشیده نمی‌شود، جدیدترین Group باز است، برنامه‌های قدیمی قابل نمایش‌اند و «ثبت خرید» برای هر Row همان دارایی/برنامه درست را باز می‌کند. تصاویر Showcase نیز باید مستقیم در README GitHub Render شوند.
