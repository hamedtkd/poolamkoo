# v0.9.2 — Selectهای بلند داخل محدوده صفحه

منوی Selectهای بلند، از جمله «سهم هدف» دارایی، دیگر از بالای viewport یا مودال بیرون نمی‌زنند.

## UX

- ارتفاع منوی Select به حداکثر ۱۶rem محدود شده است.
- اگر گزینه‌ها بیشتر باشند، خود منو اسکرول می‌خورد.
- `collisionPadding` باعث می‌شود منوی بازشده حداقل ۱۲px از لبه viewport فاصله داشته باشد.
- دکمه‌های بالا/پایین Radix به‌عنوان نشانه بصری اسکرول اضافه شده‌اند.
- این اصلاح در کامپوننت مشترک `Select` انجام شده و در همه فرم‌ها و مودال‌ها اعمال می‌شود، نه فقط سهم هدف دارایی.

## Regression

Quality gate بررسی می‌کند Select مشترک هم محدودیت ارتفاع و هم collision padding داشته باشد تا dropdownهای طولانی دوباره از صفحه خارج نشوند.
