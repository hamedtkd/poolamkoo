# v0.27.3 — Runtime fetch and workspace motion hotfix

این Hotfix دو مسئله باقی‌مانده از چرخه v0.27 را می‌بندد: خطای Runtime `AbortError` هنگام cleanup آمار GitHub و نبود حس حرکت قابل‌مشاهده هنگام جابه‌جایی بین صفحات Workspace.

## Runtime

- `useGithubStats` دیگر برای cleanup از `AbortController.abort()` استفاده نمی‌کند.
- درخواست کم‌اهمیت آمار GitHub می‌تواند کامل شود، اما یک guard محلی اجازه `setState` بعد از unmount را نمی‌دهد.
- Browser Release Smoke دیگر `AbortError` را به‌صورت عمومی نادیده نمی‌گیرد تا این کلاس خطا دوباره پنهان نشود.

## Motion

- Route جدید با یک حرکت کوتاه و بسیار کم‌رنگ وارد می‌شود و هیچ exit animation روی کل صفحه وجود ندارد.
- Route در هیچ فریمی transparent نمی‌شود؛ opacity اولیه 0.97 است.
- `MotionReveal` برای کارت‌های Dashboard محسوس‌تر شده ولی از opacity صفر استفاده نمی‌کند.
- صفحات اصلی Workspace از کلاس `workspace-stagger` استفاده می‌کنند تا آیتم‌های بالاتر زودتر و آیتم‌های پایین‌تر با delay کوتاه ظاهر شوند.
- انیمیشن‌ها فقط transform/opacity هستند و `prefers-reduced-motion` را رعایت می‌کنند.

## Data safety

- IndexedDB schema همچنان 6 است.
- هیچ migration، تغییر Backup، Market provider یا telemetry مالی جدیدی وجود ندارد.
- Service Worker cache به `poolamkoo-v48` افزایش یافته است.
