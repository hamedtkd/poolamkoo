# v0.8.0 — اتصال قیمت بورس و صندوق‌های قابل معامله

## هدف نسخه

دارایی بورسی دیگر فقط یک ردیف با قیمت دستی نیست. کاربر می‌تواند نماد واقعی بورس تهران را جست‌وجو و به دارایی متصل کند تا قیمت فعلی سبد، مبلغ پیشنهادی معامله و Snapshotهای بازار با داده واقعی به‌روز شوند.

## Provider بازار بورس

- Provider جدید `TindexProvider` اضافه شد.
- Tindex برای API توسعه‌دهنده توکن رایگان ارائه می‌کند و داده نمادهای بورس تهران را با منبع TSETMC برمی‌گرداند.
- قیمت‌های API بورس به ریال هستند و قبل از ورود به مدل داخلی پولم‌کو به تومان تبدیل می‌شوند.
- فقط نمادهایی که واقعاً به سبد کاربر متصل شده‌اند Refresh می‌شوند؛ کل بازار در هر بار بارگذاری دریافت نمی‌شود.
- خطای یک نماد باعث شکست Refresh باقی سبد نمی‌شود.
- BrsApi همچنان Provider طلا، ارز و رمزارز است.

## UX ساخت دارایی

برای نوع‌های «سهام / بورس» و «صندوق سرمایه‌گذاری» بخش «اتصال به بورس» اضافه شد:

1. کاربر عبارتی مثل `عیار`، `سیمین`، `فولاد` یا `شستا` را جست‌وجو می‌کند.
2. نتیجه شامل نماد، نام، آخرین قیمت و تغییر روزانه است.
3. با انتخاب نتیجه، شناسه بازار به دارایی ذخیره می‌شود.
4. قیمت فعلی از Provider می‌آید و قیمت دستی فقط نقش fallback را دارد.

اگر توکن Tindex تنظیم نشده باشد، همان مسیر قیمت دستی قبلی بدون خراب‌شدن جریان کار باقی می‌ماند.

## ارزش‌گذاری و خرید/فروش

- Portfolio ابتدا Quote زنده/Cacheشده را استفاده می‌کند و در نبود Quote به `manualPriceToman` برمی‌گردد.
- این fallback در Dashboard، Reports و پیشنهاد Rebalance نیز یکسان شد.
- ثبت خرید تاریخی یا موجودی اولیه دیگر قیمت fallback یک دارایی متصل به بازار را با قیمت قدیمی خرید overwrite نمی‌کند.
- بازکردن مودال خرید/فروش برای نماد متصل، آخرین قیمت بازار را به‌عنوان قیمت پیشنهادی وارد می‌کند.
- جدول سبد مشخص می‌کند قیمت از Market Provider آمده یا دستی است.

## نمودار بازار

نمادهای بورسی/ETF متصل‌شده به Select نمودار سرمایه‌گذاری اضافه می‌شوند. نمودار همچنان فقط Snapshotهای واقعی ذخیره‌شده روی همان دستگاه را نمایش می‌دهد و هیچ تاریخچه مصنوعی ساخته نمی‌شود.

## تنظیمات

متغیر جدید:

```text
TINDEX_API_TOKEN=
```

توکن فقط باید در Environment سمت سرور نگهداری شود. برای استفاده عمومی یا تجاری، شرایط استفاده و محدودیت درخواست Tindex باید بررسی شود.

## فازهای بعدی پیشنهادی

1. دریافت History واقعی بورس برای نمودارهای ۱ ماه / ۳ ماه بدون انتظار برای Snapshotهای محلی.
2. نمایش NAV برای ETFهای طلا/نقره در صورت موجود بودن داده معتبر.
3. Watchlist بازار مستقل از دارایی‌های سبد؛ بدون تبدیل پولم‌کو به اپ معامله‌گری.
4. Migration helper برای اتصال دارایی‌های دستی قدیمی مثل «عیار» به نماد واقعی با یک کلیک.
