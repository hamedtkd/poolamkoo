# v1.0.0-rc.1 — Release candidate validation

این نسخه اولین Release Candidate برای v1.0 است. هدف آن Feature جدید نیست؛ **Feature freeze** برقرار است و فقط Release-blockerها باید در این شاخه اصلاح شوند.

## وضعیت Candidate

- Automated release gate همان مسیر Production واقعی است: `npm run check:release`.
- دستور `npm run check:rc` همان Gate کامل را اجرا می‌کند و سپس هم‌ترازی Version/Docs/Schema مربوط به RC را کنترل می‌کند.
- IndexedDB روی **schema 8** باقی می‌ماند؛ Backup/Recovery/Device Transfer format تغییر نمی‌کند.
- Public/Workspace PWA boundary، worker-specific update dismissal و Local Data Health recovery boundary همان قراردادهای سخت‌شده v0.43 هستند.
- هیچ Provider جدید، backend مالی، حساب کاربری، cloud sync یا Feature Family جدید وارد RC نشده است.

## Manual acceptance قبل از v1.0 stable

این موارد عمداً جایگزین Browser Smoke نشده‌اند و باید روی Candidate واقعی انجام شوند:

1. نصب و Update واقعی PWA روی یک Chromium desktop.
2. نصب/اجرای PWA روی یک mobile-class browser و کنترل Offline/Resume.
3. یک Backup → Restore round-trip با داده غیرنمایشی و بررسی Recovery Snapshot قبل از replacement.
4. بازکردن همان Origin با یک old-tab هنگام upgrade و بررسی blocked/versionchange flow بدون Clear Site Data.
5. کنترل Light/Dark و مسیرهای اصلی در viewportهای موبایل و دسکتاپ.

اگر یکی از این موارد blocker نشان دهد، فقط همان blocker در RC بعدی اصلاح می‌شود. در غیر این صورت Candidate می‌تواند به v1.0.0 stable ارتقا پیدا کند.
