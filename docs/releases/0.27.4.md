# v0.27.4 — CSS stagger motion and AbortError hardening

این Hotfix مسیر انیمیشن Workspace را از runtime کتابخانه Motion جدا می‌کند و خطای باقی‌مانده `AbortError` در آمار GitHub را از مسیر Promise/AbortSignal خارج می‌کند.

## Runtime stability

- `useGithubStats` دیگر از `fetch`، `AbortController` یا `AbortSignal` استفاده نمی‌کند.
- درخواست تزئینی آمار GitHub با `XMLHttpRequest` callback-based اجرا می‌شود و cleanup فقط یک `active` guard را خاموش می‌کند؛ عمداً request در teardown abort نمی‌شود.
- جست‌وجوی نماد بازار نیز برای جلوگیری از پاسخ stale از request id استفاده می‌کند و به AbortController متکی نیست.
- Browser Release Smoke دیگر `AbortError` را ignore نمی‌کند؛ وقوع دوباره آن باید Release Gate را قرمز کند.

## Workspace motion

- `tailwindcss-animated@2.1.0` به پروژه اضافه و در Tailwind CSS v4 با `@import "tailwindcss-animated"` فعال شده است.
- dependency مربوط به `motion` از runtime پروژه حذف شده است.
- کل Route دیگر animate نمی‌شود؛ جابه‌جایی Next.js بین صفحات یک container پایدار دارد.
- آیتم‌های واقعی صفحه جداگانه و با فاصله‌های حدود 55ms وارد می‌شوند.
- بر اساس جایگاه، از `animate-fade-up`، `animate-fade-down`، `animate-fade-left` و `animate-fade-right` استفاده می‌شود.
- Headerها معمولاً از بالا، کارت‌های متوالی از پایین و دو ستون روبه‌روی هم از چپ/راست وارد می‌شوند.
- Dialog، Alert Dialog، Drawer، Toast، Tooltip، Network Banner و active navigation indicator نیز از utilityهای CSS استفاده می‌کنند.
- `prefers-reduced-motion` تمام entrance animationهای جدید را غیرفعال می‌کند.
- هیچ محتوای حیاتی برای visible بودن به hydration یک animation runtime وابسته نیست.

## Release protection

Browser Release Smoke روی Production Build علاوه بر navigation و dialog visibility، وجود animationهای کامپایل‌شده `tailwindcss-animated` و delayهای متفاوت را در DOM/Computed Style بررسی می‌کند تا stagger صرفاً یک class بدون CSS خروجی نباشد.

IndexedDB schema همچنان `6` است. Backup/Restore، Device Transfer، PWA entry boundary، market providers و Background Push backlog تغییری نکرده‌اند. Service Worker cache در این نسخه `poolamkoo-v49` است.
