# v1.0.0-rc.3 — Product-tour spotlight stabilization

RC2 قبل از تکمیل Gate کامل Release منتشر شد و Candidate قابل قبول برای stable نبود. RC3 هنوز Tag/Release نشده است؛ **Feature freeze** برقرار است و تا زمانی که `npm run check:rc` کاملاً سبز نشود منتشر نمی‌شود.

## blocker مشاهده‌شده

- در RC2 هندسه Spotlight در Production Browser Smoke پایدار نبود.
- نسخه اولیه RC3 Overlay را به SVG mask cutout تبدیل کرد، اما Browser Smoke واقعی نشان داد مرحله اول راهنما گاهی قبل از تثبیت viewport/target، Spotlight و Overlay دقیق مربوط به `new-money` را هم‌زمان پیدا نمی‌کند.
- این خطا نشان داد تست Desktop نباید به viewport پیش‌فرض Chromium وابسته باشد و Hook راهنما هم نباید با یک missing موقت Target، اندازه معتبر قبلی را فوراً از دست بدهد.

## اصلاح RC3

- Production Browser Smoke از ابتدا viewport دسکتاپ را صریحاً روی `1280×900` تثبیت می‌کند و بعد برای بخش Mobile به `425×800` می‌رود؛ بنابراین انتخاب Desktop/Mobile step دیگر به viewport پیش‌فرض مرورگر وابسته نیست.
- Spotlight و SVG Overlay نام Target فعال را با `data-tour-target` حمل می‌کنند و Gate دقیقاً همان Target مرحله جاری را بررسی می‌کند، نه هر Spotlight موجود در DOM.
- Hook راهنما برای پیدا شدن Target تا چند frame retry می‌کند، بعد از `scrollIntoView` دوباره اندازه‌گیری می‌کند و یک missing موقت هنگام scroll/resize دیگر Rect معتبر را پاک نمی‌کند.
- `ResizeObserver` به همان Element واقعی Target متصل می‌شود و تغییر سایز آن را تا پایان مرحله دنبال می‌کند.
- Browser diagnostics حالا وضعیت Target/Spotlight/Overlay، viewport و mobile media-query را جداگانه چاپ می‌کند تا شکست بعدی مبهم نباشد.
- Overlay همچنان یک SVG mask با Cutout شفاف واقعی است؛ Target از نظر بصری زیر لایه تیره قرار نمی‌گیرد.

## مرز Release

- IndexedDB همچنان **schema 8** است.
- Backup/Recovery/Device Transfer contract تغییر نکرده است.
- Provider، backend مالی، account system، cloud sync یا Feature Family جدیدی اضافه نشده است.
- `npm run check:rc` باید قبل از Commit/Tag/Release کاملاً سبز شود.

## Manual acceptance قبل از v1.0.0 stable

بعد از Gate خودکار، راهنمای سریع روی Desktop و Mobile واقعی مرور شود: Target باید روشن داخل Cutout دیده شود، Ring دقیقاً دور همان کنترل باشد و هیچ مرحله‌ای به Target پنهان اشاره نکند. بقیه سناریوهای نصب/Update PWA، Backup → Restore، old-tab upgrade و Responsive/Theme همچنان الزامی‌اند.
