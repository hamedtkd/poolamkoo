# v0.11.0 — Watchlist Decision Tools

این نسخه دیده‌بان بازار را از یک فهرست ساده به ابزار تصمیم‌گیری پیش از خرید تبدیل می‌کند.

## جست‌وجو، فیلتر و مرتب‌سازی

- جست‌وجوی محلی بین نام و نمادهای دیده‌بان، با نرمال‌سازی فارسی.
- فیلتر نمادهای داخل سبد، خارج از سبد، زیر NAV و بالای NAV.
- مرتب‌سازی بر اساس رشد/افت روزانه، بیشترین تخفیف یا حباب NAV، نام نماد و زمان افزودن.
- خلاصه سریع تعداد نمادها، نمادهای مثبت امروز، فرصت‌های زیر NAV و نمادهای بالای NAV.

## سیگنال NAV

- صندوق‌های حداقل ۰.۵٪ زیر NAV با برچسب «تخفیف» مشخص می‌شوند.
- صندوق‌های حداقل ۰.۵٪ بالای NAV با برچسب «حباب» مشخص می‌شوند.
- فاصله‌های کوچک با وضعیت «نزدیک NAV» نمایش داده می‌شوند.
- نبود NAV به‌صورت صریح «NAV منتشر نشده» نمایش داده می‌شود و هیچ داده تخمینی ساخته نمی‌شود.

## جزئیات سریع نماد

- هر کارت دیده‌بان دکمه جزئیات دارد و بدون ترک صفحه قیمت، تغییر روز، NAV و فاصله از NAV را نشان می‌دهد.
- تاریخچه واقعی ۱ ماه / ۳ ماه Tindex داخل همان دیالوگ نمایش داده می‌شود و Snapshotهای واقعی دستگاه fallback هستند.
- نمادی که هنوز خریداری نشده، از همان پنجره می‌تواند مستقیم به فرم ساخت دارایی منتقل شود.

## کیفیت

- helperهای مستقل برای فیلتر، مرتب‌سازی، خلاصه دیده‌بان و وضعیت NAV اضافه شده‌اند.
- تست‌های regression برای تصمیم‌گیری دیده‌بان اضافه شده‌اند.
- Service Worker cache به `poolamkoo-v23` ارتقا یافته است.
