# Product showcase panels

This directory contains the presentation artwork used by the repository READMEs.

## Included assets

- **English panels**: the canonical GitHub showcase used in `README.md`
- **Persian panels**: the localized presentation set used in `README.fa.md`

## Important rules

- These images are built from Poolamkoo's approved visual identity and real product-screen references.
- They are promotional presentation assets, **not** pixel-exact screenshots of the application.
- All financial values shown in the panels are illustrative/demo values.
- No panel may be generated from a real user browser profile, personal financial backup, or private production data.
- Exact product screenshots remain under `docs/assets/screenshots/` and come from the isolated fake-data capture workflow.
