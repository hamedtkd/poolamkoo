# Product showcase panels

These English presentation panels are built from Poolamkoo's approved visual identity and real product-screen references. They are promotional compositions for the public GitHub README, not pixel-exact application screenshots.

- All financial values shown in the panels are illustrative/sample values.
- The panels must never be generated from a real user browser profile or private financial backup.
- Exact production UI screenshots remain under `docs/assets/screenshots/` and are generated with the isolated fake-data capture workflow.
- Persian presentation variants are intentionally kept outside the repository for social-media publishing to avoid duplicating large binary assets and to keep GitHub's canonical product showcase in English.
