## Manual acceptance

Manual acceptance سناریوهای Release روی Candidate نهایی تأیید شده است:

- **Desktop guide:** مراحل راهنمای سریع Target روشن و Ring هم‌تراز دارند و مرحله‌ای به کنترل پنهان اشاره نمی‌کند — Pass.
- **Mobile guide / responsive:** راهنما و مسیرهای اصلی در viewport موبایل قابل استفاده‌اند — Pass.
- **Chromium desktop PWA install/update:** نصب و رفتار Update/«بعداً» بدون blocker — Pass.
- **Mobile Offline/Resume:** Workspace و داده محلی بعد از Offline/Resume سالم می‌مانند — Pass.
- **Backup → Restore:** round-trip و بازگشت داده بدون blocker — Pass.
- **old-tab upgrade:** upgrade روی همان Origin بدون نیاز به Clear Site Data و بدون blocker داده — Pass.
- **Light/Dark + responsive:** مسیرهای اصلی روی موبایل و Desktop بدون blocker بصری — Pass.
